Аватары видов: `Buddy.species(name, { size })`, `Buddy.speciesList`. Двадцать шесть SVG 160×160 в `assets/Species/`.

| Группа | Ключи |
| --- | --- |
| Домашние | `sp-cat`, `sp-dog`, `sp-rabbit` |
| Грызуны и мелкие | `sp-hamster` (хомяк), `sp-guinea` (морская свинка), `sp-rat` (крыса), `sp-ferret` (хорёк) |
| Птицы | `sp-bird` (общая птица), `sp-parrot` (попугай), `sp-canary` (канарейка), `sp-pigeon` (голубь), `sp-owl` (дикая птица) |
| Рептилии и земноводные | `sp-turtle` (черепаха), `sp-lizard` (ящерица), `sp-snake` (змея), `sp-frog` (лягушка) |
| Фермерские | `sp-horse`, `sp-goat`, `sp-sheep`, `sp-cow`, `sp-pig`, `sp-hen` |
| Дикие | `sp-fox`, `sp-hedgehog`, `sp-owl` |
| Служебные | `sp-paw` (другое), `sp-unknown` (не уверен) |

**Правила.** Один вид — одна голова-персонаж без тела (змея и ящерица с хвостом-акцентом): читается от 40 px. Размер 40 (пин карты), 52 (выбор вида), 72–120 (заглушка фото). Если у случая есть фото, оно главнее аватара; аватар остаётся заглушкой и маркером на карте. Не добавляйте новым видам цвета вне палитры системы: у каждого вида один основной цвет с градиентом вверх-вниз, щёки `#FF8FA8` на 60%, глаза `#241F4A`.

**Как вид попадает в приложение.** Ключ вида (`hamster`, `parrot`, `snake`) связан с аватаром через `SP_ART` и с группой через `SPECIES_BY_GROUP`. Выбор вида показывает вкладки «Кошки и собаки», «Грызуны и мелкие», «Птицы», «Рептилии»: внутри вкладки не больше пяти аватаров и «Другое». Для каждого вида задаются окрасы, породы или подвиды, пример примет, короткий совет по уходу и ссылка на памятку (`SPEC_INFO`). Подробности: `16-podhvat.md`, раздел 16.
