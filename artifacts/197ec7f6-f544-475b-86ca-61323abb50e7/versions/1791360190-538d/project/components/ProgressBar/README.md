Индикаторы прогресса на светлой поверхности: непрерывная полоса и сегментированный счётчик.

```js
Buddy.ProgressBar({ value: 72, tone: 'orange' })            // полоса 0–100
Buddy.ProgressBar({ segments: 8, value: 3, tone: 'sky' })   // 3 из 8
```

**Полоса** (`bd-bar`): высота 10px, дорожка `track`, заливка в тоне категории (`violet`, `orange`, `green`, `sky`, `pink`). Ширина анимируется за `dur-slow` с `ease-out`.

**Сегменты** (`bd-meter`): высота 8px, зазор 4px. Для счётных привычек: стаканы воды, подходы, страницы.

**Правила.**
- Цвет заливки совпадает с цветом иконки категории: вода голубая, сон оранжевый, движение зелёное.
- Значение всегда дублируется числом рядом (`3/8`) и ролью `progressbar` с `aria-valuenow`. Заливка сама по себе не несёт смысла.
- Статус «Poor / Good / Great» пишется словом над полосой, не цветом.
