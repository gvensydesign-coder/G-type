Базовая поверхность для группировки: `bg-surface`, радиус `radius-xl`, отступ `space-4`, мягкая тень `shadow-sm`.

| Вариант | Класс | Где |
| --- | --- | --- |
| Default | `bd-card` | Карточка на `bg-app`. Тёмная тема получает контур `border-subtle`, потому что тени там не видно. |
| Flat | `bd-card--flat` | Список внутри листа: без тени, с контуром. |
| Tint | `bd-card--tint` | Вторичная группа на белом листе: `bg-surface-tint`. |
| Large | `bd-card--lg` | Акцентные блоки: радиус `radius-2xl`, отступ `space-5`, `shadow-md`. |

**Правила.**
- Правило вложения: радиус вложенного элемента равен радиусу родителя минус отступ (24 − 8 = 16).
- Один слой: не кладите карточку на карточку той же заливки. Внутри `bd-card` используйте `bg-surface-tint` или `bg-surface-sunken`.
- Не рисуйте цветную полоску слева. Акцент даёт иллюстрация, плитка-иконка или бейдж.
