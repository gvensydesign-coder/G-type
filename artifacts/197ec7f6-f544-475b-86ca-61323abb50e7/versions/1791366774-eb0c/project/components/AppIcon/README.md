Иконка приложения: мастер 1024 × 1024 SVG и 30 PNG для iOS, Android (включая adaptive и монохромную), строки состояния, favicon и PWA.

```js
Buddy.appIcon(60)                                    // iOS-скругление 22.37%
Buddy.appIcon(48, { shape: 'circle' })               // круг (Android launcher)
Buddy.appIcon(24, { src: 'app-icon-mono', shape: 'none' })
```

**Состав.** Buddy-голова на градиенте `violet-400 → violet-700`, облака внизу. Без текста. iOS: полный квадрат без прозрачности. Android adaptive: слои `background` и `foreground`, арт внутри круга 66dp из 108dp (61%). Монохромная версия для themed icons Android 13+ и белый силуэт для строки состояния.

**Правила.** Не добавляйте текст и мелкие детали, иконка читается на 29px. Не скругляйте сами: маску ставит система. Для maskable (PWA) образ остаётся в безопасной зоне 80%. Для iOS 18 подготовьте тёмный (фон `violet-900`) и тонированный (оттенки серого) варианты. Полная таблица размеров: раздел «Виджеты, уведомления и иконка приложения».
