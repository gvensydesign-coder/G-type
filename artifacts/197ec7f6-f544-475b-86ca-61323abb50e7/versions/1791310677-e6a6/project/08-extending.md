# Как расширять и использовать

## Структура библиотеки

```
tokens.json                  единственный источник токенов (цвет, шрифты, отступы, радиусы, размеры, z-index, прозрачность, длительности, кривые, тени)
tokens.css                   генерируется из tokens.json (переменные --name, классы типографики, блоки тем)
components/bundle.css        стили компонентов, градиенты, анимации
components/bundle.js         иконки, маскоты, объекты и билдеры компонентов (window.Buddy)
components/<Name>/README.md  правила применения
components/<Name>/preview.html  живая витрина
assets/Mascots, Objects, Icons  SVG-ассеты и icons.json
```

## Именование

| Тип | Схема | Пример |
| --- | --- | --- |
| Токен цвета (шкала) | `<hue>-<step>` | `violet-600` |
| Токен цвета (роль) | `<группа>-<роль>[-<вариант>]` | `bg-surface-raised`, `text-on-brand` |
| Отступ, радиус, размер | `space-N`, `radius-<size>`, `size-<name>` | `space-5`, `radius-xl` |
| Класс компонента | `bd-<компонент>[__часть][--вариант]` (БЭМ) | `bd-habit__title`, `bd-btn--dark` |
| Состояние | `is-*` и ARIA | `is-done`, `aria-pressed`, `aria-current` |
| Ассет | `<имя>-<настроение>.svg` | `buddy-streak.svg` |

## Использование в CSS и в коде

```css
.my-card { background: var(--bg-surface); color: var(--text-primary); border-radius: var(--radius-xl); box-shadow: var(--shadow-sm); padding: var(--space-4); }
```

Переключение темы: `document.documentElement.dataset.theme = 'dark'`. Вложенная тема на контейнере: `<section data-theme="dark">`. Системная тема: слушайте `matchMedia('(prefers-color-scheme: dark)')` и выставляйте атрибут.

**Tailwind (пример).** Привяжите утилиты к переменным, чтобы темы работали без `dark:`:

```js
theme: { extend: { colors: { surface: 'var(--bg-surface)', app: 'var(--bg-app)', ink: 'var(--text-primary)', brand: 'var(--brand)' }, borderRadius: { xl: 'var(--radius-xl)', '2xl': 'var(--radius-2xl)' }, boxShadow: { md: 'var(--shadow-md)' } } }
```

**React и другие фреймворки.** Билдеры возвращают строки HTML: оберните в компонент с `dangerouslySetInnerHTML` для прототипа или перепишите разметку из README компонента (структура и классы описаны там), стили остаются прежними.

## Импорт токенов в дизайн-инструменты

`tokens.json` лежит в списковой форме для страницы системы. Для Figma Variables / Tokens Studio:

1. Цвета: создайте коллекцию с режимами `Light` и `Dark`, переменная на каждый токен семантики (`bg-*`, `text-*`, `border-*`, `brand*`, `accent-*`, статусы). Шкалы импортируйте в отдельную коллекцию `Primitives` и свяжите алиасами, как в файле (`{violet-600}`).
2. Числа: `space-*`, `radius-*`, `size-*` как переменные типа Number.
3. Текст: стили из `type.groups` (семейство, размер, строка, вес, трекинг).
4. Тени: effect styles из `shadow-*`, светлые и тёмные значения как два режима.
5. Иконки: перетащите SVG из `assets/Icons` (штрих `#26215F`, замените на цвет слоя). Маскоты и объекты импортируются как есть.

## Как добавить…

**Цвет бренда / акцент.** Добавьте шкалу `<hue>-50 … 700` в `color.tokens`, затем роли `accent-<hue>`, `accent-<hue>-soft`, `accent-<hue>-ink` с двумя темами. Проверьте пары `on-accent` и `*-ink` на 4.5:1 (матрица в разделе «Цвет и темы»). Добавьте тон `bd-tile--<hue>`, `bd-bar--<hue>`, `bd-meter--<hue>` в `bundle.css`.

**Категорию привычки.** Выберите существующий акцент по таблице «Цвета категорий» либо заведите новый (см. выше), добавьте иконку и объект.

**Иконку.** Добавьте имя и разметку на сетке 24px в `assets/Icons/icons.json` и в объект `ICONS` в начале `components/bundle.js` (одна и та же строка внутренней разметки), затем положите покрашенный файл `assets/Icons/<имя>.svg`. Правила: штрих 2px, круглые окончания, без заливок.

**Маскота.** По рецепту из раздела «Иллюстрации и маскоты». Затем впишите его в таблицу ролей и в `Mascots/preview.html`.

**Компонент.** 1) Опишите классы `bd-<name>` в `bundle.css` только через токены; 2) добавьте билдер в `bundle.js` и тип в `index.d.ts`; 3) создайте `components/<Name>/README.md` и `preview.html` (светлая и тёмная тема проверяются автоматически через `data-theme`); 4) если у компонента есть интерактив, подключите его в `Buddy.wire`.

**Тему.** Добавьте в `color.themes` новый `id`, затем заполните значения семантических токенов. Шкалы не меняются. Обязательные кандидаты: `high-contrast` (тексты 7:1, границы 3:1) и `colorblind`.

## Контрольный список перед релизом компонента

- [ ] Цвета, отступы, радиусы, тени, длительности только из токенов.
- [ ] Светлая и тёмная темы проверены визуально, пары текста ≥ 4.5:1, контролы ≥ 3:1.
- [ ] Видимый фокус (`ring-focus`), зона нажатия ≥ 44px, `aria-label` на иконках.
- [ ] Статус не только цветом.
- [ ] Анимации из каталога, выключаются при reduced-motion.
- [ ] README с правилами и «что передаёт потребитель», живое превью.
- [ ] Не более одного маскота и одной primary-кнопки в сборке.

## Версионирование

Семантическая версия в `Buddy.version`. Смена значения токена роли: patch; новый токен или компонент: minor; переименование или удаление токена и класса: major (сохраните алиас на один релиз).
