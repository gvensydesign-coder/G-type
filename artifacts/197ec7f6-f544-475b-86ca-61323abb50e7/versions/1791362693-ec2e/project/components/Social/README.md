Иконки соцсетей 2026 (Simple Icons 16.34, CC0): плитка 512, цветной глиф и монохром для 23 сервисов, плюс кнопки входа, строка «Поделиться» и строка подключённого аккаунта.

```js
Buddy.social('telegram', { size: 52 })                    // плитка (по умолчанию)
Buddy.social('x', { variant: 'mono', size: 20 })          // монохром, цвет от родителя
Buddy.SocialButton({ social: 'google' })                  // «Continue with Google», 56px
Buddy.ShareRow({ items: ['telegram', 'whatsapp', 'vk'] })
Buddy.SocialAccount({ social: 'telegram', handle: '@lukman', connected: true })
```

**Что передаёт потребитель.** Название сервиса словами (подпись или `aria-label`, он уже в SVG), обработчики нажатий и состояние подключения. Фирменные цвета в токенах `social-<имя>`.

**Правила.** Плитку не перекрашивайте и не накладывайте тень на глиф. Размеры 24 / 36 / 52 / 60. Вход через Apple обязателен при других сторонних входах. Чёрные марки в цветном варианте берут `text-primary`. LinkedIn отсутствует в источнике (удалён правообладателем): берите знак из его брендбука. Источник, лицензия и порядок добавления: раздел «Иконки соцсетей».
