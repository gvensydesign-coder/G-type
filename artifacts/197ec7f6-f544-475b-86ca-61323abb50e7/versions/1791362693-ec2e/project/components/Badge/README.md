Малая метка: счётчик (`3/8`) или статус со словом и иконкой.

```js
Buddy.Badge({ text: '3/8', tone: 'orange' })
Buddy.Badge({ text: 'Done', tone: 'success', icon: 'check-circle', size: 'sm' })
```

**Счётчик.** 28px, Nunito 800 14px, радиус `radius-md`, цвет по категории.

**Статус** (`size: 'sm'`): 22px, `label-sm`, иконка 16px слева. Тона `success`, `warning`, `danger`, `info`: фон `*-soft`, текст и иконка `success`, `warning`, `danger`, `info` (4.5:1 в обеих темах).

**Правила.**
- Статус всегда состоит из слова и иконки. Цвет усиливает, но не заменяет: пара успех/ошибка не различается по оттенку красного и зелёного.
- Не вкладывайте бейджи друг в друга и не ставьте больше одного бейджа на строку.
