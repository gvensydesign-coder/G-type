`Buddy.Podhvat.mount(root, options)` собирает приложение «Подхват» (помощник для человека, нашедшего животное) из компонентов системы. Весь сценарий работает без сервера и хранится в `localStorage` (`podhvat.buddy.state`).

```js
Buddy.Podhvat.mount(document.getElementById('app'), {
  photos: { dog, cat, rabbit, goat, catMatch }, // data-URL; без них показываются аватары видов
  tools: true,     // боковая панель просмотра: роли, тема, повтор знакомства
  persist: true,   // сохранять состояние
  fit: true,       // масштабировать телефон по высоте окна
  skipBoot: false, // пропустить заставку
  theme: 'light',  // или 'dark'
  state: {}        // начальное состояние, например { page: 'case', role: 'volunteer' }
});
```

Экраны, роли и логика: `16-podhvat.md`. Компоненты приложения (шаг маршрута, карта с пинами, карточка ленты, итог, нижняя шторка связи, быстрый набор, степпер, сегменты) описаны там же и подключены стилями `pd-*` в `bundle.css`.
