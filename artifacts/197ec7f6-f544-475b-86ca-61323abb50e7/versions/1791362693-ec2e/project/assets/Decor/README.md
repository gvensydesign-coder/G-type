Мягкие 3D-элементы в многоцветном SVG: облака `cloud-3d-lg`, `cloud-3d-md`, `cloud-3d-sm` и их ночные версии `*-night` для тёмной темы, шар `orb-3d` и сердце `heart-3d`.

Каждый шар шейдится отдельным радиальным градиентом со светом сверху слева, контуров нет, под облаком размытая лавандовая тень. Размеры по токенам `size-cloud-sm | md | lg`. В коде используйте `Buddy.cloud(size)` (сам выбирает дневную или ночную версию) и `Buddy.decor(name)`. Построение и правила размещения: раздел «Фирменные приёмы».
