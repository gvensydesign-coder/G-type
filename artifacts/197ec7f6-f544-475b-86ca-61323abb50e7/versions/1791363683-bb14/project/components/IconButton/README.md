Круглая кнопка только с иконкой: 44px (36px в компактном варианте) с зоной нажатия не меньше `size-touch`.

| Вариант | Класс | Где |
| --- | --- | --- |
| Стандартная | `bd-iconbtn` | Панели инструментов на `bg-app`, `bg-surface-sunken`. |
| Soft | `bd-iconbtn--soft` | Вложения и камера в поле ввода. |
| Glass | `bd-iconbtn--glass` | Только на градиенте шапки: меню, колокольчик, поиск. Полупрозрачная заливка + blur 12px. |
| Send | `bd-iconbtn--send` | Отправка сообщения: 48px, `bg-inverse`. |

```js
Buddy.IconButton({ icon: 'bell', label: 'Notifications', variant: 'glass', dot: true, size: 'sm' })
```

**Что передаёт потребитель.** Обязательно `label`: он становится `aria-label`. Иконка из набора Icons, размер 24px (20px в `sm`).

**Правила.**
- Красная точка уведомления (`dot: true`) только на колокольчике, обводка точки цвета фона шапки.
- Группа из двух-трёх кнопок на шапке собирается в `bd-pill-group` с общей стеклянной подложкой.
- Иконка в кнопке всегда `currentColor`: цвет задаёт вариант, не подкрашивайте вручную.
