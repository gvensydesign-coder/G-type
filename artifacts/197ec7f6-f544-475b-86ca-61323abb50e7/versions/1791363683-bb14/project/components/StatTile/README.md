Плитка метрики дня: иллюстрация сверху, подпись, крупное число, единица. Три плитки в ряд на градиентной шапке.

```js
Buddy.StatTile({ object: 'water-glass', label: 'Water', value: '3', unit: 'Glass' })
Buddy.StatTile({ mascot: 'sunny-sleepy', label: 'Sleep', value: '8.5', unit: 'Hours' })
```

**Строение сверху вниз.** Арт 44px, зазор `space-3`, подпись `caption` `text-secondary`, значение `number-md` (Nunito 800), единица `caption` `text-muted`. Радиус `radius-xl`, тень `shadow-md`.

**Сетка.** `bd-grid-3`: три равные колонки с зазором `space-2` (8px). Плитки перекрывают нижний край шапки.

**Правила.**
- Иллюстрация всегда по центру и одной высоты во всех плитках.
- Значение короткое: число или одно слово. Длинные тексты переносите в карточку метрики.
- Для метрики сна используйте маскота Sunny Sleepy, для воды и упражнений объекты `water-glass` и `bike`.
