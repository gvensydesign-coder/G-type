Карта ключевых экранов «Подхвата» в двух темах: главная со свёрнутым чатом Скаута и разделом «Самопомощь», профиль, уведомления, база знаний, медали, нейро-чат, организации с тегами и чат с голосовым сообщением. Новые экраны v1.13 (выбор вида по вкладкам, сканер, доверие и безопасность) собраны в карточке `PodhvatFlow`. Скриншоты собираются тем же кодом, что и прототип: Buddy.Podhvat.mount(..., { state: { page } }).

С v1.14 на экранах живой 3D-Скаут (главная, нейро-чат); модули зверей подгружает превью. База знаний показана с новым рядом тем и круглым полем поиска.
