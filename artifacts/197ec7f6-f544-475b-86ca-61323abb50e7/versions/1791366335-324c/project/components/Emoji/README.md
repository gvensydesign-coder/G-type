Цветные иллюстративные иконки в стиле эмодзи: `Buddy.emoji(name, { size })`, `Buddy.emojiList`. Восемнадцать SVG 64×64 в `assets/Emoji/`.

| Назначение | Ключи |
| --- | --- |
| Теги организаций и волонтёров | `clock`, `gift`, `wallet`, `pin`, `star`, `car-sky`, `car-orange`, `house`, `siren`, `shield`, `moon`, `heart` |
| Самопомощь (статьи) | `bolt`, `firstaid`, `stop`, `weather`, `bowl`, `search` |

Для статей про животных используются аватары видов (`Buddy.species`). **Правила.** Один предмет, мягкий градиент от светлого к насыщенному, один блик, тень-эллипс. Без контуров и текста внутри. Размер 24–32 в тегах и значках, 40–48 в списках. Линейные иконки (`Buddy.icon`) остаются для действий и навигации: эмодзи заменяют их только там, где нужно быстро «считать» категорию глазами.
