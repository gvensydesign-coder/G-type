# Фирменные приёмы

Три приёма, которые делают Buddy узнаваемым и которые вы отметили в референсе: живой узор из квадратиков, мягкие 3D-элементы и блоки, из которых выходит иллюстрация.

---

## 1. Узор-раздумье (Thinking Grid)

Фон чата заполнен сеткой маленьких квадратиков. Рядом с маскотом они крупнее и теплее (оранжевый), к краям мельчают и холодеют (фиолетовый). Узор не просто красив: он показывает, что делает ассистент.

### Состояния

| Состояние | Когда | Движение | Цвет | Текстовый статус |
| --- | --- | --- | --- | --- |
| `idle` | Ждёт сообщение | Дыхание полутона 7 секунд, редкие искры | фиолетовый → оранжевый у маскота | нет |
| `thinking` | Принял запрос, думает | Два кольца расходятся от маскота (цикл 2 секунды) | кольцо оранжевое | «Thinking…» |
| `searching` | Ищет информацию, вызывает инструменты | Луч сканирует экран по диагонали, найденные ячейки вспыхивают оранжевым | луч оранжевый | «Searching…» |
| `answering` | Печатает ответ | Колонки «падают» сверху вниз с разной скоростью, как набор текста | тёплый и холодный вперемешку | «Writing…» |
| `success` | Ответ готов, задача выполнена | Одна зелёная волна от маскота 1.4 секунды, затем автоматический возврат в `idle` | `pattern-ok` | «Done» |
| `sleep` | Нет сети, ошибка, пауза | Приглушённое медленное дыхание, без красного | фиолетовый | «Offline» |

Переходы между состояниями плавные: два поля смешиваются за 450ms.

### Устройство

- Сетка: шаг `pattern-pitch` (10px), максимальный квадратик `pattern-cell` (5px).
- Поле интенсивности: ровная площадка вокруг фокуса (16% короткой стороны), дальше спад `(1 − d / R)^1.25`, где `R` = 62% длинной стороны. Фокус по умолчанию `x 50%, y 36%`, ставьте его в центр маскота.
- Размер квадратика = `pattern-cell × уровень` (5px), прозрачность квадратика 0.24–0.9, умноженная на общий множитель `pattern-opacity` = 0.5 (50%). Ячейки слабее 10% не рисуются.
- Цвета берутся из токенов `pattern-cool`, `pattern-warm`, `pattern-ok` и пересчитываются при смене темы. Узор вдали от фокуса холодный, ближе тёплый, волна успеха зелёная.
- Рендер: canvas, 30 кадров в секунду, пауза вне экрана (IntersectionObserver) и на скрытой вкладке, масштаб до 2× по плотности экрана.

### Использование

```js
const host = document.querySelector('.chat-bg');             // position: relative
const pat = Buddy.Pattern.mount(host, { focus: { x: 0.5, y: 0.3 } });
pat.set('thinking');                                         // idle | thinking | searching | answering | success | sleep
status.innerHTML = Buddy.ThinkingIndicator({ label: 'Thinking…' });   // текстовый статус рядом
pat.set('success');                                          // сам вернётся в idle через 1.9 секунды
pat.destroy();
```

Параметры `mount`: `state`, `focus {x, y}` в долях, `pitch`, `cell`, `radius` (доля длинной стороны), `intensity` (множитель прозрачности, по умолчанию токен `pattern-opacity` 0.5), `fps`, `autoReturn`.

Без JavaScript: класс `bd-pattern-static` рисует статичный узор CSS-маской (квадраты 4px на шаге 10px с радиальным затуханием вокруг 50% / 36%).

### Правила

1. **Только декор.** Каждое состояние сопровождается текстом (`ThinkingIndicator` с `role="status"`), узор сам ничего не сообщает.
2. **Под контентом.** Слой узора лежит на `z-base`, интерактивные элементы и текст выше. Текст на узоре остаётся читаемым: квадратики мелкие и не плотнее 16% площади.
3. **Один слой на экран.** Не ставьте узор на карточки, шапку и списки: только на фон чата, пустых состояний и экрана ожидания.
4. **Движение.** При `prefers-reduced-motion` и `data-motion="off"` рисуется один статичный кадр состояния. Смена состояния обновляет кадр.
5. **Без красного.** Ошибка не окрашивается в красный: состояние `sleep` и баннер с текстом.
6. **Производительность.** Не монтируйте больше двух узоров на экране и не уменьшайте `pitch` меньше 8px.

## 2. Мягкие 3D-элементы (Soft 3D)

Лёгкие, пастельные, «надувные» объёмы: облака, шары, сердце. Они дают глубину, не споря с интерфейсом.

### Набор (`assets/Decor`)

| Файл | Размер | Назначение |
| --- | --- | --- |
| `cloud-3d-lg` | токен `size-cloud-lg` (220px) | Угол экрана, фон чата, облако под несколькими элементами |
| `cloud-3d-md` | `size-cloud-md` (132px) | Облако под маскотом на карточке |
| `cloud-3d-sm` | `size-cloud-sm` (72px) | Акцент между слоями |
| `cloud-3d-*-night` | то же | Фиолетовая версия для тёмной темы, подставляется автоматически |
| `orb-3d` | 20–40px | Пузыри мысли, декор вокруг маскота |
| `heart-3d` | 56–96px | Благодарность, «нравится», финалы |

Плоское облако `Objects/cloud` остаётся для иконок и мелких плиток. Крупные поверхности только в 3D.

### Рецепт построения

1. Форма из шаров: облако 5–6 кругов разного радиуса, нижние крупнее, верхние выше. Никаких контуров.
2. Каждый шар закрашивается своим радиальным градиентом, центр света на 36% / 28% (сверху слева): `#FFFFFF → #F4F1FF (50%) → #DDD7F6 (82%) → #C9C1EE`. Ночная версия: `#B3A8F6 → #8A7DE0 → #5F54C2 → #453B9C`.
3. Блики: на верхних шарах размытый (σ 2.5) белый эллипс, повёрнут на −18°, прозрачность 85% (40% в ночной версии).
4. Мягкая тень под облаком: эллипс `#8F84D6`, размытие σ 5, прозрачность 30%. В CSS поверх добавляется `drop-shadow(0 10px 18px rgba(120,100,200,.16))`.
5. Палитра только из лаванды и белого. Цветной 3D (сердце) разрешён один на экран.

### Размещение

- **Углы экрана**: облако обрезается краем (`right: −96px`, `left: −110px`), прячется за контентом. Максимум три облака на экран.
- **Под маскотом**: среднее облако смещено на `−14px` влево и `−18px` вниз относительно карточки: ступни и облако частично выходят за край (см. приём 3).
- **Слои глубины**: далёкое облако мельче и бледнее, ближнее крупнее. Дрейфуют с разной фазой (`--drift-delay`).
- **Z-порядок**: облака под контентом (`z-base`), сердце и шары над ним, но не над текстом.
- **Анимация**: `bd-cloud--drift`, 9 секунд (`dur-drift`), смещение 8px по x и 6px по y. Один маскот и одно облако не качаются синхронно.
- **Тёмная тема**: `Buddy.cloud()` выводит дневную и ночную версии, CSS показывает нужную по `data-theme`.

```js
Buddy.cloud('lg', { style: 'right:-96px;top:84px', delay: '-3s' });
Buddy.decor('heart-3d', { size: 64, cls: 'bd-anim-float', style: 'position:absolute;right:70px;bottom:70px' });
```

### Не делайте

- Не используйте белые облака на тёмной теме без ночной версии.
- Не размещайте облака поверх текста и кнопок.
- Не делайте их ярче маскота и не добавляйте им лица.

## 3. Блоки с выходом за границу (Pop-out)

Иллюстрация выходит за край карточки или баннера: уши маскота поднимаются над верхней гранью, лапа выглядывает за левую. Блок кажется живым и объёмным, а маскот не заперт в рамке.

### Токены

| Токен | Значение | Что определяет |
| --- | --- | --- |
| `bleed-sm` | 12px | Боковой вылет. Не больше: поле экрана 20px минус `space-2` |
| `bleed-md` | 20px | Стандартный верхний вылет: уши и голова |
| `bleed-lg` | 36px | Крупный вылет для акцентного баннера |

### Правила отступов

1. **Верхний вылет входит в отступ блока.** `margin-top = space-3 + вылет`. Блок с вылетом 20px получает 32px сверху, и расстояние от соседа до самой высокой точки иллюстрации остаётся `space-3`.
2. **Боковой вылет внутри полей экрана.** Иллюстрация выходит за край блока не больше чем на `bleed-sm`, поэтому не касается края экрана (поле 20px, запас 8px).
3. **Текст не заходит под иллюстрацию.** Отступ текстовой колонки со стороны иллюстрации = ширина арта − `bleed-sm` + `space-2` (для арта 128px это 124px).
4. **Блок не обрезает арт.** `overflow: visible`, фон рисуется на самом блоке со скруглением. Облако и тени лежат на `z-base`, иллюстрация на `z-raised`, текст на `z-raised`.
5. **Позиция арта считается от его содержимого, а не от рамки файла.** В файле над ушами есть прозрачное поле (14.4% высоты). Верх арта = `−(вылет + поле)`. Для Leafy и Buddy Streak поля иные: `Buddy.popArt` знает их.
6. **Один вылет на блок.** Не выводите иллюстрацию за две грани одновременно, кроме пары «верх + левая лапа».
7. **Соседние блоки с вылетом** разделены минимум `space-6`, иначе уши касаются карточки выше.

### Компоненты

- `ProgressCard`: Buddy (140px) выходит на 20px вверх и на 10px влево, 3D-облако под ним выступает за левый и нижний край.
- `PopBanner`: промо-блок. Тона `hero`, `sunny`, `leafy`, `soft`. Сторона `right` или `left`. Вылет `md` (20px) или `lg` (36px).
- Исторический пример: Leafy стоит на верхнем крае плиток на главной.

```js
Buddy.PopBanner({ tone: 'sunny', title: 'Sleep challenge', text: 'Seven nights, one cozy streak', cta: 'Join' });
Buddy.PopBanner({ tone: 'leafy', title: 'Start small', text: 'One minute a day', cta: 'Try it', over: 'lg', side: 'left' });
```

```html
<section class="bd-pop bd-popbanner bd-popbanner--sunny" style="--pop-over: var(--bleed-md)">
  <img class="bd-pop__art" style="width:128px; top:-38px; right:-8px" src="sunny-happy.svg" alt="">
  <h3 class="bd-popbanner__title">…</h3> <p class="bd-popbanner__text">…</p> <button class="bd-btn bd-btn--dark">Join</button>
</section>
```

### Доступность

Иллюстрация декоративна (`alt=""`), вся информация в тексте. Кнопка единственная и находится вне зоны вылета. Контраст текста на фоне блока 4.5:1: на `hero-card` текст `text-on-hero`, на мягких фонах `text-primary` и `text-secondary`.
