# Продукт «Подхват»: система, собранная из прототипа

«Подхват» помогает человеку, который нашёл бездомное или потерянное животное, не остаться с ним один на один: создать случай за минуту, подключить соседей, волонтёров и организации и довести историю до проверенного итога. Прототип из архива разобран на роли, статусы и логические цепочки; на этой основе система Buddy расширена и приложение собрано заново: `Buddy.Podhvat.mount(root, options)`.

## 1. Ядро логики

| Принцип | Что значит в интерфейсе |
| --- | --- |
| Эстафета ответственности | У случая всегда один явный ответственный: нашедший, помощник, организация или владелец. Он показан в шапке («Сейчас отвечает») и в блоке «Следующий шаг». |
| Отклик ≠ принятие | Ответ организации и согласие волонтёра не меняют статус на «передано». Передача подтверждается обеими сторонами; приём организацией подтверждается отдельно. |
| Свежесть места | Последнее наблюдение хранит время и автора. Если нашедший ушёл или животное пропало, место помечено «требует проверки», а помощникам не показывается как актуальное. |
| Итог только по подтверждению | Итог «владельцу», «на передержке», «принято организацией» доступен после соответствующих подтверждений; «не найдено» только после отметки «ушло». Заметка не короче 8 символов. |
| Совпадение ≠ владелец | Сходство по фото даёт повод связаться. Владелец подтверждается скрытой приметой, и только потом открывается передача. |
| Дикие и фермерские | Для диких животных волонтёрам доступно только наблюдение издалека, а решения принимает специалист. Для фермерских сначала уточняется место. |

## 2. Роли

Прототип показывает один случай с четырёх точек зрения; переключатель ролей вынесен за пределы телефона (панель просмотра), как в оригинале.

| Роль | Главный экран | Следующий шаг |
| --- | --- | --- |
| Нашедший | Герой «Вы нашли. Мы подхватим.», быстрые сценарии, карта | Проверить место → предложить задачу → подтвердить передачу → зафиксировать итог |
| Волонтёр | «Ваши задачи» | Принять или отклонить задачу → выполнить → подтвердить получение |
| Организация | «Запросы организации» | Ответить на запрос → подтвердить фактический приём |
| Владелец | «Ваш питомец» | Назвать скрытую примету → подтвердить получение |

## 3. Карта экранов

`splash → welcome → onboarding (5) → home`

- **Создание случая:** `capture` (группа и вид, фото, место) → `draft` (проверка подсказок) → `case`. Срочный путь: `emergency` → `case`.
- **Случай:** вкладки «Сейчас» (следующий шаг, к кому обратиться, поиск хозяина), «Маршрут» (живая лента шагов, участники, подтверждения передачи), «Пока ждём» (три чек-пункта и передача наблюдения). Из случая: `outcome`, `match`, `share`, `flyer`.
- **Сообщество:** `nearby` (карта и лента) → `nearbyDetail` (задача: предложено → назначено → выполнено), `orgs` → `orgDetail`, `volunteers` → `volDetail`.
- **Связь:** `support`, `chat`, `call`, шторка «Связь» из верхней панели, быстрый набор на главной.
- **Личное:** `profile` (контакты, фото, карточка питомца), `notifications` (фильтры, прочитано, переход к цели), `flyer`.

## 4. Что добавлено в систему

**Токены.** `map-land`, `map-block`, `map-road`, `map-park`, `map-water` (светлая и тёмная схема карты).

**Маскоты.** Два новых персонажа: кошка Misty (misty-happy) и пёс Scout (scout-happy). Scout отвечает в чате поддержки, оба встречают на заставке и экране знакомства, Misty живёт в пустых состояниях.

**Ассеты.** Группа «Species»: 16 аватаров видов (`Buddy.species`). 12 новых иконок: `paw`, `pin`, `phone`, `building`, `siren`, `file-text`, `briefcase`, `navigation`, `route`, `shield`, `map`, `funnel`.

**Компоненты (`pd-*`).**

| Компонент | Назначение |
| --- | --- |
| Шаг маршрута (`pd-route`) | Узлы «сделано / сейчас / впереди», пульсирующий текущий шаг |
| Следующий шаг (`pd-next`) | Градиентная карточка с одним главным действием; варианты `--warn` и `--ok` |
| Шапка случая (`pd-case`) | Фото или аватар вида, статус, последнее наблюдение, ответственный |
| Карта (`pd-map`, `pd-pin`) | Иллюстративная карта из токенов, пины с аватарами видов, превью случая |
| Карточка ленты (`pd-feed`) | Статус, дистанция, подтверждение, действие |
| Выбор вида (`pd-spgrid`) | Сетка аватаров 3×N вместо выпадающего списка |
| Итог (`pd-out`) | Радио-карточки с блокировкой, пока нет подтверждений |
| Сегменты и степпер | Вкладки случая; шаги создания |
| Шторка связи (`pd-sheet`) | Нижняя шторка со стеклом вместо всплывающего меню |
| Быстрый набор (`pd-quick`) | Стеклянные кнопки над таб-баром только на главной |
| Счётчик (`bd-count`) | Число непрочитанных на колокольчике |
| Листовка (`pd-flyer`) | Цифровая карточка для чатов, каналы VK, Telegram, Max, WhatsApp |

## 5. Что улучшено относительно прототипа

- Явный «Следующий шаг» на каждой роли вместо набора равноправных кнопок.
- Обратная связь после действий: уведомление сверху («Запрос отправлен», «Итог сохранён»).
- Выбор вида: аватары вместо списка; разные формулировки для домашних, фермерских, диких.
- Контакты: шторка «Связь» учитывает контекст (организация, волонтёр, задача рядом).
- Чат: ответ с индикатором набора вместо мгновенной реплики.
- Карта: цвета из токенов, поддержка тёмной темы, пины с видами, превью случая.
- Переходы между экранами: плавное появление содержимого без перерисовки шапки и таб-бара; панель навигации и узор остаются на месте, а все кнопки нажимаются и отпускаются плавно.
- Чат поддержки собран из компонентов диалога системы: шапка со статусом, маскот-аватар, пузыри, готовые вопросы, стеклянный композер, узор за сообщениями реагирует на ответ.
- Телефон масштабируется по высоте окна, таб-бар и быстрый набор стеклянные.
- Знакомство: пять иллюстраций, жесты листания, узор из квадратиков в фоне.
- Иконки Icons8 заменены собственными, фото-заглушки заменены аватарами видов.

## 6. Ограничения

Карта, расстояния, чат, звонки, подсказки ИИ, push и публикации в соцсети показаны как сценарий и ничего не отправляют. Принадлежность к организации не проверяется. Для реального сервиса нужны согласия на геолокацию и фото, подтверждение организаций и модерация.

## 7. Нейро-чат, голос, видео и теги (v1.4)

**Нейро-чат со Скаутом.** Открывается по логотипу в верхней панели. Пустое состояние собрано по шаблону экрана «Чат» системы: узор из квадратиков, облака, три предмета над маскотом, заголовок `display-lg`, ряд подсказок и большой композер `bd-chat`. Дальше экран превращается в диалог: шапка со статусом, пузыри с аватаром, готовые вопросы, узор реагирует на «думаю», «смотрю материал», «пишу ответ» и «готово».

| Возможность | Как работает в прототипе |
| --- | --- |
| Голосовой ввод | Микрофон в композере: запись с таймером и волной, после остановки в поле подставляется пример фразы. Настоящее распознавание речи в демо не используется. |
| Подсказки и готовые ответы | Чипы с частыми вопросами и ответы по ключевым словам с карточкой памятки. |
| База знаний | 10 памяток для самопомощи с поиском: первые 5 минут, раненое животное, агрессия, кошка, собака, птенец, дикие животные, жара и холод, кормление, поиск хозяина. |
| Фото и видео | Скрепка и камера принимают файл. Видео и фото показываются в диалоге, а разбор заготовлен: черновик для карточки, предупреждение об ограничениях и кнопка «Создать случай по фото». |

**Аудиосообщения и видеозвонок.** В чате с поддержкой, организацией, волонтёром и участниками: пока поле пустое, вместо отправки стоит микрофон. Нажатие запускает запись (отмена и отправка), сообщение показывается с проигрывателем и волной. Кнопка с камерой в шапке чата и в карточках организаций и волонтёров открывает видеозвонок: соединение, таймер, микрофон, камера, завершение. Длительность звонка записывается в чат. Камера и микрофон устройства не используются.

**Теги организаций и волонтёров.** Сверху на страницах «Организации» и «Волонтёры» лента фильтров с иконками: круглосуточно, бесплатно, платно, рядом, рейтинг 4.8+, срочно, выезд, приём, проверено, на машине, вечером, передержка. Фильтры суммируются. В карточке те же признаки показаны круглыми значками, рядом рейтинг и аватары видов, которых принимают. В деталях значки расшифрованы подписями.

**Маскоты.** Все медведи в приложении заменены на пса Scout и кошку Misty.

**Ревью на соответствие системе.** Шкала шрифтов приведена к токенам (12, 14, 16, 20, 24, 28, 32, 40, 56), отступы и скругления к шагам системы, размер иконок к 16, 20, 24, 32, цвета только из токенов, зоны нажатия не меньше 44 pt, блок заголовка страницы собран в один элемент с одинаковым шагом.

## 8. Награды платформы, оживление и глубина главной (v1.5)

**Награды у организаций и волонтёров.** Десять наград платформы построены на компоненте `Medal` системы: «Первая помощь», «Быстрый отклик», «Ночной дозор», «Спасатель», «Проверенный», «Колёса помощи», «Высокий рейтинг», «Тёплый дом», «Командный игрок» и лимитированная «Тёплый октябрь». Рядом с именем в карточке показаны до трёх полученных наград и счётчик, в карточке партнёра есть строка «Награды платформы». Нажатие открывает страницу наград по образцу экрана достижений системы: градиентная шапка, тост `MedalToast`, секции «Получено», «Как получить» (закрытые с прогрессом) и «Лимитированная серия». Нажатие на награду открывает шторку: большая медаль, описание, дата получения и счёт или прогресс с подсказкой, как её получить.

**Оживление персонажей.** Все маскоты получили встроенную анимацию (см. README маскотов). На главной и в нейро-чате Scout и Misty встроены как `Buddy.live`: следят за курсором головой и глазами, подпрыгивают при касании, задумываются, пока Скаут «печатает», и радуются, когда ответ готов.

**Цветные иконки-эмодзи** (`Buddy.emoji`) заменили линейные значки в тегах, фильтрах и в разделе самопомощи.

**Главная.** Заголовок «Вы нашли — мы подхватим». Плашка стала матовой (полупрозрачное стекло с мелким зерном), на фоне мягкие размытые пятна розового, оранжевого, голубого и фиолетового оттенков, а от иконки нейро-чата в левом углу расходится узор из квадратиков по радиусу.

## 9. Иллюстрации вместо иконок, самопомощь, уведомления, профиль (v1.6)

**Объекты вместо линейных значков.** Плитки в списках, карточках, тегах, уведомлениях и настройках теперь показывают иллюстрации из библиотеки «Объекты». Недостающие предметы дорисованы в том же стиле и добавлены в библиотеку (30 новых). Предметы-эмодзи отдельным набором больше не нужны: он объединён с «Объектами».

**Самопомощь.** Статьи оформлены карточками по образцу `AgentCard`: цветная обложка с тремя иллюстрациями по теме, заголовок и внизу одна строка «О чём», «О ком» или «Для кого».

**Уведомления** собраны по экрану «Уведомления» системы: заголовок с кнопкой «прочитано», фильтры-чипы, группы «Сегодня» и «Вчера», цветные плитки с иллюстрациями или маскот, акцентный фон и точка у непрочитанных, кнопки «Открыть» и «Прочитано».

**Профиль** по образцу экрана профиля: аватар с уровнем, прогресс опыта, статистика, витрина наград, настройки. Добавлено: награды пользователя за реальные действия (знакомство, первый случай, фото, чат, листовка, база знаний, профиль, команда, итог), карточка заполнения профиля со списком пунктов, карточка питомца и каналы для листовок. Редактирование данных вынесено на отдельный экран, а настройки на свой экран: уведомления, радиус помощи, приватность, тема, спокойный режим, очистка чатов. Радиус поиска влияет на ленту и карту рядом, переключатели уведомлений на список, контакт по умолчанию на листовку.

## 10. Несколько фото и видео, карточка животного, исправления (v1.7)

**Карусель медиа.** Везде, где есть фото, поддерживается набор фото и видео: прокрутка жестом, точки и счётчик «1/3», стрелки при наведении, запоминание позиции при обновлении экрана. Карусель используется в карточке животного рядом, в создании случая (загрузка нескольких файлов, миниатюры с удалением), в черновике и шапке случая, в листовке, в карточке питомца (до 6 фото) и в чатах (фото, видео и файлы PDF в одном сообщении).

**Карточка животного рядом.** Верхняя панель убрана, остаётся только кнопка «назад» в виде иконки поверх фото. Фото занимает фон сверху, а вся информация лежит на плашке с закруглением по верхним углам, которая заходит на фото. Статус-бар на фото светлый.

**Исправления.** Шапка чата с длинным названием больше не выталкивает кнопки за край: заголовок сокращается с многоточием. В чат добавлена кнопка «прикрепить». Затемнение узора на главной сдвинуто выше: узор держится до 264 pt от верха и гаснет к 612 pt.

## 11. Плоские внутренние экраны, поиск рядом, профиль в настройках (v1.8)

**Внутренние экраны без верхней панели.** База знаний и статья, организации и волонтёры (списки и карточки), настройки, редактирование профиля, листовка, итог, совпадение, срочный сигнал, звонок и черновик показывают только кнопку «назад» в виде иконки, содержимое поднято выше. Верхняя панель (нейро-чат, связь, уведомления, профиль) остаётся только на основных вкладках.

**Поиск и фильтры в «Все случаи рядом».** Поле поиска (вид, место, примета) и кнопка фильтров со счётчиком активных. Панель фильтров: вид животного (аватары), что нужно (статусы), где искать («рядом со мной» с радиусом 1, 3, 5, 10 км или «другой район» по названию места), сортировка «ближе» и «свежее». Список, счётчик «Найдено» и пины на карте работают от одного набора условий. В ленте добавлены три случая (ёж, птенец, рыжая кошка) для проверки фильтров.

**Профиль в настройках.** Карточка с именем, фамилией, фото (сменить, убрать) и районом. Группа «Геолокация»: переключатель определения местоположения (запрос у устройства; если доступа нет, используется демо-район «Центральный») и радиус поиска.

## 12. Раздел «Мы на связи» по образцу экрана трекера (v1.9)

Структура повторяет экран «Трекер» системы: градиентная шапка с заголовком и стеклянными кнопками, большая карточка с маскотом поверх шапки, парные карточки метрик и список. Скаут зовёт связаться репликой в облачке («С чего начать? Напишите мне или позвоните!») и следит за курсором. В карточке график недели (ежедневная работа поддержки, часы 8:00–22:00) и две кнопки «Написать» и «Позвонить». Ниже плитки способов связи: чат поддержки, нейро-чат, звонок и видеозвонок. Дальше карточки метрик (время ответа за неделю, доля вопросов, решённых с первого ответа), частые вопросы со ссылками на памятки, другие контакты, предупреждение про единый номер 112 и примечание о конфиденциальности.

**Нейро-чат (v1.9.1).** Облака на стартовом экране убраны, предметы над маскотом сменяют друг друга каждые 3 секунды (набор из четырёх троек: вода, миска, аптечка, камера и так далее), заголовок разбит на «Привет!» и «Чем помочь?». Подсказки на старте переносятся в две строки целиком, в диалоге они прокручиваются и затухают у края.

**«Мы на связи» (v1.9.2).** Шапка плавно растворяется в фоне без резкой границы, иконки справа убраны, на фоне страницы пульсирует узор из квадратиков (состояние «думаю», затухает книзу).

**Главная (v1.9.3).** Размытие матовой плашки увеличено с 28 до 50 px (примерно на 80%), размытые пятна на фоне светлее примерно на 40%.

**«Мы на связи» (v1.9.4).** Пульсирующий узор теперь лежит сверху поверх шапки и гаснет к карточке, тёмное затухание остаётся внизу. Реплика Скаута короче и мельче: «Напишите или позвоните!».

## 14. QR-код, метка на ошейник, перетекающий таб-бар (v1.11)

**QR-код карточки.** В карточке случая (вкладка «Сейчас»), в листовке (найденного и своего питомца) и в карточках профиля (питомец и передержка) есть QR-код, который ведёт на карточку. Код строится встроенным генератором (`qrcode-generator`, MIT), уровень коррекции M, всегда тёмный на белом, чтобы читался в тёмной теме. В демо ссылка ведёт на адрес прототипа с якорем `#case-0241` или `#pet`; в рабочем сервисе здесь будет публичная короткая ссылка карточки.

**Метка на ошейник.** Страница `tagprint` («Метка на ошейник»): объяснение, зачем нужна метка, живой предпросмотр листа A4, переключатель «Показывать мой контакт на метке» (по умолчанию выключен) и кнопка «Скачать PDF для печати». Лист: три полосы для ошейника (QR, заголовок, описание: вид, окрас, порода, при желании контакт) и четыре малые метки, пунктир для вырезания. Для своего питомца и найденного тексты разные. PDF собирается в браузере (холст 200 dpi, JPEG, один объект изображения), через capability `downloads` (запасной вариант: ссылка `download`). Тексты листа следуют выбранному языку.

**Таб-бар.** Активная плашка теперь отдельный элемент `.pd-tabind`: при смене вкладки она сначала растягивается до новой иконки (170 мс), затем сжимается до её ширины с лёгкой пружиной, как жидкость. Первое появление без анимации, при `prefers-reduced-motion` переход мгновенный.

**«Связь».** Рамка карточки обрезана по центру маскота: Скаут стоит на фоне, а карточка начинается на уровне его середины. Раздел поднят. Реплика в пузыре меняется при каждом входе и каждые 6,5 секунды: 14 фраз, часть полезных, часть успокаивающих.

**Мэтч.** Если найденное животное уже есть в базе по точным признакам (ID-слепок, адресник, номер чипа, цвет ошейника, окрас), карточка находки попадает в раздел «Мэтч» (`matches`, `matchItem`). Правило: совпал вид и один точный признак (слепок, адресник, чип) либо два общих (окрас, ошейник). Карточка совпадения: вкладка «Сравнение» (критерии с галочками, у незаполненных подсказка), «Дополнить» (окрас, ошейник, адресник, чип, комментарий, загрузка новых фото, «Сохранить и сверить заново»), «История» (что произошло и хронология из базы вместе с вашими записями). Подтверждение владельца идёт через скрытую примету: статусы `new` → `check` → `confirmed` или `rejected`. Точки входа: строка «Мэтч» на главной, уведомление, баннер в сканере, кнопка в маршруте случая.

**Первичный тест.** Чип «Первичный тест» на главной и в чате. Скаут задаёт шесть вопросов (вид, состояние, метки, поведение, где находится, как давно), каждый с вариантами-чипами и полосой прогресса. Итог: вердикт трёх уровней (срочная помощь, нужно внимание, спокойно), заполненная карточка, до четырёх рекомендаций со ссылками (организации, волонтёры, сканер, памятка) и кнопка «Создать случай с этими данными», которая подставляет ответы в форму находки. Это предварительная оценка, не диагноз.

**Услуги и помощь.** В карточках организаций и волонтёров появился раздел с услугами: статья, цена или «бесплатно», выбор нужного и запрос исполнителю. Волонтёры разделены по видам: врач, юрист, передержка, зоотакси, зоопсихолог, кинолог, фотограф, помощь с поиском. В списке волонтёров фильтр по виду и карточки с кратким перечнем услуг и диапазоном цен.


**Единое знакомство (версия 58).** Отдельные экраны знакомства и «Показать сценарий» объединены в один пошаговый показ поверх живого приложения: пользователь одновременно видит экран и читает пояснение. Путь: заставка → имя и контакт (необязательно) → 11 шагов (Скаут, вопрос боту, первичный тест, форма находки, маршрут случая, ID-слепок, мэтч, проверка владельца, «Рядом», организации с услугами, финал истории) → главная. На заставке и на первом шаге есть «Пропустить». Тексты бывших экранов знакомства («Не нужно знать всё заранее», «Помощь складывается из шагов» и др.) стали заголовками соответствующих шагов.

**Несколько случаев, чаты, избранное (версия 64).** Состояние одного случая вынесено в `CASE_DEFAULTS`/`CASE_KEYS`: текущий случай лежит в `s`, остальные паркуются в `s.cases` (`{id, title, snap, threads}`) через `parkLive()` и возвращаются `switchCase(id)`. Если случаев больше одного, строка на главной и вкладка «Случай» ведут на страницу `cases` («Активные случаи»: счётчики, карточки со статусом, помощником и числом чатов, блок «Завершённые»); в шапке случая появляется плашка со ссылкой на все находки. Нижние быстрые кнопки: «Избранное», «Чаты», «Поддержка».

**Чаты.** Страница `chats` с вкладками «Активные» и «Архив». Чат привязывается к случаю (`s.chatCase[target]`); когда случай закрыт итогом, его переписка уходит в архив и открывается только для чтения (`s.chatArch`, плашка «Переписка в архиве»). Чат поддержки всегда в активных.

**Избранное.** Состояние `s.fav = {vol, org, svc, animal}`; сердечко `favBtn(type, id)` стоит сверху карточек организаций, волонтёров, услуг, случаев «Рядом» и животных из базы мэтча. Страница `favorites` группирует по типам и категориям (вид помощи волонтёра, тип организации, поставщик услуги, статус животного), с фильтром-чипами и пустым состоянием.

**Тест на заботу.** Второй чип в чате Скаута: шесть вопросов (вид, возраст, состояние, жильё, срок, ветеринар) и план заботы из пяти блоков: место, питание, здоровье, стресс, документы; зависит от ответов.

**Пол и габариты, документы питомца.** В карточке находки и в карточке питомца: пол и размер (`sizeOpts` подбирает диапазоны веса под вид) плюс необязательный вес; участвуют в критериях мэтча. В карточке питомца раздел «Документы»: чип, прививки с датой ревакцинации, ветпаспорт, регистрация в базе животных РФ (демо-проверка по номеру чипа).
