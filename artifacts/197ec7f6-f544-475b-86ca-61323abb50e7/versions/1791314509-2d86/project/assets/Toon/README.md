Модули 3D-зверей: восемь самодостаточных файлов `*-toon.js` (≈0.4–0.5 МБ каждый, WebGL2, без зависимостей). Каждый создаёт глобальный объект (`CatToon`, `DogToon`, `BunnyToon`, `FoxToon`, `BearToon`, `PandaToon`, `RaccoonToon`, `HamsterToon`) с методом `mount(el, options)` и свойством `clips` (список из 15 анимаций с названиями и описаниями).

Подключайте только нужных зверей: `<script src="dog-toon.js">` на странице или `fetch(...)` + вставка текста в `<script>` (в превью системы так и сделано). Обёртка и правила: компоненты `Toon`, `ToonReactions` и `Buddy.Toon` в бандле. Настройки эффекта по умолчанию: контур 0, полутон 0.42.

В `<img>` модули не работают: нужен DOM и WebGL2.
