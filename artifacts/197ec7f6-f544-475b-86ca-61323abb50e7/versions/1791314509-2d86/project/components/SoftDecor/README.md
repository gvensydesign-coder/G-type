Мягкие 3D-элементы: облака трёх размеров, шар и сердце. Лёгкие пастельные объёмы с светом сверху слева, без контуров.

```js
Buddy.cloud('lg', { style: 'right:-96px;top:84px', delay: '-3s' });   // day + night версии, дрейф 9 секунд
Buddy.cloud('md', { keep: true, drift: false });                       // только дневная, на тёмной поверхности карточки
Buddy.decor('heart-3d', { size: 64 });
```

**Что передаёт потребитель.** Абсолютное позиционирование через `style` (контейнер `position: relative`), размер из `sm | md | lg`. Тёмная тема подхватывается сама: выводится ночная фиолетовая версия.

**Правила.**
- До трёх облаков на экран, у краёв и за контентом. Углы обрезаются краем экрана.
- Далёкие облака мельче, ближние крупнее, фазы дрейфа разные.
- Сердце цветное: не больше одного на экран, над облаками, не над текстом.
- Облако на тёмной карточке (`hero-card`) берёт `keep: true`: остаётся белым.
- Не накладывайте на кнопки и текст, не добавляйте лица.

Построение и размещение: раздел «Фирменные приёмы».
