Строка привычки: плитка-иконка 40px, название, расписание и круглая отметка справа.

```js
Buddy.HabitRow({ object: 'bottle', tone: 'sky', title: 'Drink Water', meta: 'Every 30 minutes', checked: true })
```

**Строение.** Фон `bg-surface-tint` (на белом листе) или `bd-habit--raised` (`bg-surface` + `shadow-sm` на `bg-app`). Радиус `radius-lg`, отступы 12/16. Название `label-lg`, расписание `body` в `text-muted`.

**Отметка** (`bd-check`): 28px, пустая с контуром `border-control`, выполненная заливается `accent-green` с галочкой `on-accent`. Нажатие: пружинный pop за `dur-base` и всплеск конфетти (`Buddy.burst`). Название выполненной строки переходит в `text-secondary`, зачёркивания нет.

**Что передаёт потребитель.** Название глаголом, расписание коротко («Every 30 minutes», «End of the day»), тон по категории привычки (см. палитру категорий в README).

**Правила.**
- Зона нажатия строки не меньше `size-touch`. Нажатие по строке открывает детали, по кружку отмечает.
- Список строк через `space-3`. При появлении используйте `bd-stagger` (шаг 60ms).
- Отметка не отменяется свайпом без подтверждения. Снять отметку можно повторным нажатием.
