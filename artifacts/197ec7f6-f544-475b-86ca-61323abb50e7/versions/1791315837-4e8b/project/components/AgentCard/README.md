Карточка каталога: градиентная обложка 168px с плитками интеграций, название, описание и автор.

```js
Buddy.AgentCard({ title: 'Workout Buddy', desc: 'Short sessions that fit your day', cover: 'sunset', apps: ['dumbbell', 'bike', 'flame'], by: 'Buddy Team' })
```

**Обложки.** `aurora` (небо + лаванда), `sunset` (розовый + жёлтый), `candy` (сирень + розовый), `lagoon` (бирюза + зелень). Градиенты собраны из шкал цвета и одинаковы в обеих темах: обложка всегда яркая. Плитки интеграций белые, 56px, `radius-lg`, `shadow-md`.

**Строение.** Внешняя карточка `radius-xl` с внутренним отступом 8px, обложка `radius-xl − 8px`. Название `headline`, описание `body` `text-secondary`, автор: аватар 28px + «by **Name**».

**Правила.**
- Логотипы сервисов подставляются официальными знаками. В превью стоят иконки-заглушки из набора.
- Hover: подъём на 3px за `dur-base` и `shadow-md`.
- Сетка: две колонки на десктопе с зазором 24px, одна на телефоне. Название одной строкой, описание не длиннее 45 символов.
