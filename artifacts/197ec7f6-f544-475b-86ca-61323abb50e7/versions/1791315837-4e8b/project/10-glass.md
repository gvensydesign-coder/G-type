# Стекло и размытие (Glass)

Полупрозрачные панели с размытием заднего плана: контент просвечивает, поэтому панель визуально занимает меньше места. Применяется к плавающему таб-бару, тостам, уведомлениям, композеру диалога и кнопкам на шапке.

## Токены

| Токен | Светлая | Тёмная | Назначение |
| --- | --- | --- | --- |
| `glass-bg` | белый 78% | `#1D1946` 78% | Стеклянная панель: таб-бар, док |
| `glass-bg-strong` | белый 90% | `#1D1946` 90% | Панели с текстом: тост, push, композер |
| `glass-active` | белый 88% | белый 15% | Активная вкладка внутри бара |
| `glass-border` | белый 70% | белый 16% | Светлая кромка 1px, имитация края стекла |
| `glass-on-hero` | белый 22% | белый 14% | Кнопки-иконки на градиенте шапки |
| `blur-sm` | 8px | | Чипы и кнопки на шапке |
| `blur-md` | 16px | | Тост, push, композер, шторка |
| `blur-lg` | 28px | | Таб-бар, док |
| `glass-saturate` | 1.6 | | Усиление насыщенности просвечивающих цветов |
| `shadow-glass` | | | Тень 28px и верхний блик 1px |

## Рецепт

```css
.panel {
  background: var(--glass-bg);
  -webkit-backdrop-filter: blur(var(--blur-lg)) saturate(var(--glass-saturate));
  backdrop-filter: blur(var(--blur-lg)) saturate(var(--glass-saturate));
  border: 1px solid var(--glass-border);
  box-shadow: var(--shadow-glass);
}
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .panel { background: var(--bg-surface-sunken); }   /* запасной вариант: непрозрачная панель */
}
```

Готовые классы: `bd-glass` (blur-lg, 78%) и `bd-glass--strong` (blur-md, 90%).

## Таб-бар

- Высота 60px вместо прежних 72px: вкладка 48px, отступ 6px, иконка 22px, подпись `label-sm`. Радиус `radius-2xl`.
- Расстояние до краёв экрана 12px, до низа 14px. Контент прокручивается под баром, нижний запас листа 104px.
- Неактивная вкладка `text-secondary` в светлой теме и `text-primary` в тёмной (на стекле не `text-muted`: тот слабее), активная `text-primary` на `glass-active` с верхним бликом.

## Правила

1. **Контраст считается на худшем фоне под панелью.** Светлая тема: самый тёмный контент под стеклом 78% даёт для `text-secondary` 5.5:1 и для `text-primary` выше 12:1. Тёмная тема: самый светлый контент под стеклом даёт для `text-primary` 5.8:1, но для `text-secondary` около 2.3:1, поэтому в тёмной теме подписи таб-бара берут `text-primary` (неактивные приглушены только иконкой), а под стеклом не размещайте белые плашки и облака без запаса. На светлых иллюстрациях под панелью в тёмной теме добавьте скрим (градиент в `bg-app` 60%) или перейдите на `glass-bg-strong`.
2. **Только поверх контента.** Стекло имеет смысл, когда под ним что-то есть: список, градиент, маскот. Над сплошным фоном используйте `bg-surface`.
3. **Один слой.** Не кладите стекло на стекло. Исключение: кнопки-иконки в группе `bd-pill-group` на шапке.
4. **Запасной вариант обязателен.** Без `backdrop-filter` (старые браузеры, режим экономии заряда) панель становится непрозрачной.
5. **Производительность.** Не больше двух стеклянных панелей в кадре, `blur-lg` только у таб-бара и дока. Не анимируйте сам blur.
6. **Кромка.** Всегда 1px `glass-border` и верхний блик: без них стекло сливается с фоном.
7. **Reduced transparency.** При системной настройке «Уменьшить прозрачность» подставляйте запасной вариант.
