# Типографика

## Пара шрифтов

| Роль | Семейство | Начертания | Почему |
| --- | --- | --- | --- |
| Display (заголовки, числа, реплики) | **Nunito** | 600–900 | Скруглённые окончания повторяют формы маскотов и кнопок. Цифры `8.5`, `3/8` получаются дружелюбными и читаемыми. |
| Text (интерфейс) | **Manrope** | 500–800 | Чистый геометричный гротеск, отлично держит малые размеры, широкие кириллические формы. |
| Mono | системный моноширинный | 400 | Только для кода и значений токенов в документации. |

Оба шрифта открытые (SIL OFL), поддерживают латиницу и кириллицу, доступны в Google Fonts. Подключение в `bundle.css`: `@import url("https://fonts.googleapis.com/css2?family=Manrope:wght@500;600;700;800&family=Nunito:wght@600;700;800;900&display=swap")`. Запасной стек: `system-ui, -apple-system, "Segoe UI", sans-serif`. Для приложений скачайте файлы и положите их в `fonts/`, затем перечислите в `type.fonts`.

Шаг шкалы около 1.2, строки кратны 2px, значения тянутся к сетке 4px.

## Правила

- **Иерархия двумя средствами.** Размер и вес, цвет работает вторым. Самый тёмный текст один на блок: заголовок.
- **Числа.** Всегда Nunito, в колонках `font-variant-numeric: tabular-nums`, единица измерения отдельной строкой меньше и светлее.
- **Строка.** Подпись и название в одну строку с `text-overflow: ellipsis`, описание не более двух строк. Длина текста до 65 знаков.
- **Заголовки** используют `text-wrap: balance`, чтобы не оставлять висячих слов (особенно «Hello, How / can I help you?»).
- **Вес.** Минимум 500. Для текста на цветной заливке 700.
- **Капс.** Только `overline` и только короткие метки. Для русского и длинных слов капс не применяем.
- **Выключка.** По левому краю, центр только для приветствий, пустых состояний и экрана входа.
- **Русский текст** занимает до 15% больше места: проверяйте кнопки и чипы, оставляйте запас по ширине.

```css
.title-xl { font-family: var(--font-display); font-size: 28px; line-height: 34px; font-weight: 800; letter-spacing: -0.01em; }
.body     { font-family: var(--font-sans);    font-size: 14px; line-height: 20px; font-weight: 500; }
```

Классы со стилями (`.title-xl`, `.body`, …) создаются вместе с `tokens.css`.
