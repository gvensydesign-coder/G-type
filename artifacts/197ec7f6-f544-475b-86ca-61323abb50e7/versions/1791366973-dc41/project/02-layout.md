# Сетка и композиция

Сетка референса A самая выразительная: три равные плитки, перекрытие шапки, плавающий таб-бар. Здесь она переведена в числа.

## База

| Параметр | Значение | Токен |
| --- | --- | --- |
| Единица | 4px | `space-1` |
| Эталонный экран | 390 × 844 | рамка `bd-phone` |
| Поля слева и справа | 20px | `space-5`, `size-screen-margin` |
| Ширина контента | 350px | 390 − 2 × 20 |
| Статус-бар сверху | 54px | зона под системные элементы |
| Home-индикатор снизу | 34px | зона под системный жест |
| Таб-бар | высота 72px (56px вкладка + 2 × 8px), отступ от низа 14px | `size-tabbar` |
| Нижний запас у прокрутки | 120px | чтобы последняя строка не пряталась под баром |

## Вертикальный ритм

| Между | Отступ |
| --- | --- |
| Секциями экрана | `space-6` (24px) |
| Заголовком секции и списком | `space-4` (16px) |
| Строками списка | `space-3` (12px) |
| Плитками метрик | `space-2` (8px) |
| Иллюстрацией и подписью в плитке | `space-3` (12px) |
| Внутри карточки (края) | `space-4` (16px), у крупных `space-5` (20px) |

## Сетки внутри экрана

```
Метрики (bd-grid-3): 3 колонки, зазор 8px           [111px][111px][111px]  = 350px
Карточки (bd-grid-2): 2 колонки, зазор 12px          [169px][169px]        = 350px
Неделя серии (bd-week): 7 колонок без зазора         [50px] × 7            = 350px
Сегменты прогресса: n равных капсул, зазор 6px
Столбики сна: 7 столбцов, зазор 6px
```

Колонки задаются `grid-template-columns: repeat(n, minmax(0, 1fr))`: `minmax(0, …)` позволяет тексту сжиматься, не раздвигая сетку.

## Паттерны композиции

### 1. «Шапка + лист» (Hero + Sheet)
Сверху градиентная шапка (`bd-hero`), её нижний отступ 64px. Ниже белый лист (`bd-sheet`) с радиусом `radius-3xl` и отступом −32px: лист наезжает на шапку, образуя «чашу». В шапке: действия, приветствие, маскот, плитки, hero-карточка. На листе: списки и графики.

### 2. «Перекрывающая карточка»
Карточка (серия, плитки) поднимается на 56–70px на шапку: `margin-top: −70px` и `z-index: var(--z-raised)`. Так белая поверхность «растёт» из цвета.

### 3. «Плавающий док»
Таб-бар и поле чата не прижаты к краю: отступ 12–14px по бокам и снизу, радиус 28px. Содержимое под ними прокручивается, поэтому нижний запас 120px.

### 4. «Маскот рядом с данными»
Персонаж касается карточки: стоит на её верхнем крае (Leafy на плитках), заходит на облако внутри карточки (Buddy), занимает центр пустого экрана (Sunny). Размер 56–148px, на расстоянии от текста не меньше `space-3`.

### 5. «Центральный пустой экран»
Центрированная колонка: иллюстрация 190px → заголовок (`display-xl`) → подпись (`body-lg`, `text-muted`) → чипы → поле. Всё симметрично, действия внизу под большим пальцем.

### 6. «Выход за границу» (Pop-out)
Иллюстрация выходит за край блока. Три размера вылета: `bleed-sm` 12px (сбоку), `bleed-md` 20px (сверху, стандарт), `bleed-lg` 36px (сверху, акцент).

| Сторона | Вылет | Где учитывается |
| --- | --- | --- |
| Сверху | `bleed-md` / `bleed-lg` | В отступе самого блока: `margin-top = space-3 + вылет`. От соседа до самой высокой точки арта остаётся `space-3` |
| Сбоку | не больше `bleed-sm` | Внутри поля экрана: 20px − 12px = 8px до края |
| Снизу | облако или тень до `bleed-sm` | Не залезает на следующий блок, следующий отступ `space-6` |

Блок сохраняет `overflow: visible`, фон рисуется на нём самом. Текстовая колонка уступает иллюстрации: отступ со стороны арта = ширина арта − `bleed-sm` + `space-2`. Между двумя блоками с вылетом не меньше `space-6`. Подробности и примеры: раздел «Фирменные приёмы».

### 7. «Живой фон»
Слой узора-раздумья и 3D-облака лежат под контентом (`z-base`), на пустых экранах и в чате. Фокус узора совпадает с центром маскота (`x 50%`, `y` на уровне маскота). Облака у краёв обрезаются экраном.

## Адаптивность

| Ширина | Схема |
| --- | --- |
| 360–430 | Одна колонка, поля 20px, как эталон. Сетка плиток сохраняется 3 в ряд до 340px, ниже плитки переносятся 2 + 1. |
| 431–767 | Контент центрируется, максимальная ширина 480px, остальное фон `bg-app` (или градиент). |
| 768–1279 | Две колонки: слева основной поток, справа карточки метрик (ширина 360px). Таб-бар превращается в боковую навигацию 88px. |
| 1280+ | Контейнер 960–1200px, поля страницы 40px (`space-10`), каталог в 2–3 колонки с зазором 24px (как референс B). |
