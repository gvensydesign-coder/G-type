Профиль: аватары, шапка с уровнем, статистика, группы настроек и подключённые аккаунты.

```js
Buddy.Avatar({ mascot: 'sunny-happy', size: 96, ring: true, level: 7 })
Buddy.ProfileHeader({ name: 'Lukman', handle: '@lukman', level: 7, xp: 64 })
Buddy.StatRow({ items: [{ v: '4', l: 'Day streak' }, …] })
Buddy.SettingsGroup({ title: 'Preferences', rows: [{ icon: 'bell', tone: 'orange', title: 'Notifications', control: 'switch', checked: true }] })
```

| Аватар | Размеры 32 / 48 / 56 / 72 / 96, тон по персонажу, кольцо `bd-grad-outline`, точка статуса, значок уровня |
| --- | --- |
| Строка настроек | 56px, плитка 28px, название, контрол (шеврон, значение, переключатель) |

**Правила.** Витрина показывает три последних награды, остальное на отдельном экране. Опасные действия отдельной группой внизу и с подтверждением. Статус аккаунта словом и иконкой. Анатомия: раздел «Экраны: диалог, профиль, уведомления, инсайты».
