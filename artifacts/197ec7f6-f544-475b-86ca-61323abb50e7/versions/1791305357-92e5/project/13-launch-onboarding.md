# Запуск, приветствие и знакомство

Три экрана первого впечатления и три вида загрузки. Всё собрано из токенов длительности и кривых, везде есть повтор в превью.

## 1. Заставка (Splash)

Показывается при холодном старте, минимум `dur-splash` (2400ms), пока грузятся данные. Если данные готовы раньше, анимация доигрывается, если позже, держится последний кадр с лоадером.

| Время | Что происходит | Токены |
| --- | --- | --- |
| 0 мс | Фон `bd-grad-wash`, узор в состоянии `thinking` | `pattern-*` |
| 100 мс | Большое облако влетает слева (1200ms) | `ease-emphasized` |
| 300 мс | Малое облако справа, затем дрейф | `dur-drift` |
| 350 мс | Buddy падает сверху: растягивается, приземляется со сплющиванием 1.16 × 0.84, отскок −22px, оседает (`bd-drop`, 900ms), тень растёт под ним | `dur-intro` |
| 1000 мс | Буквы «Buddy» поднимаются по одной с шагом 70ms (640ms каждая) | `ease-emphasized` |
| 1500 мс | Подзаголовок «Your little buddy for better habits» | 600ms |
| 1600 мс | Лоадер из пяти квадратиков | `bd-loader__sq` |
| 2400 мс | Узор → `success` (зелёная волна), переход на следующий экран | `dur-page` |

Правила: слово «Buddy» без анимации масштаба всего блока, только подъём букв. Звук не играем. Переход на Welcome: заставка уезжает вверх на 40px и растворяется, Buddy остаётся на месте (общий элемент).

## 2. Приветствие (Welcome)

Первый запуск. Buddy знакомится и ведёт к входу.

| Время | Что происходит |
| --- | --- |
| 200 мс | Buddy выглядывает снизу и поворачивается на −8° → 0° (`bd-peek`, 900ms, пружина) |
| 1200 мс | Buddy машет: два качания ±5° (1.4 секунды, точка вращения у ног) |
| 1000 мс и 1900 мс | Две реплики-пузыря «Hi, I'm Buddy!» и «Let's build tiny habits together» (`bd-bubble`) |
| 1500 и 1700 мс | Два шара `orb-3d` хлопают (`bd-pop`) |
| 2300 мс | Заголовок «Welcome to Buddy» и подпись поднимаются на 16px |
| 2700 мс | Кнопки «Get started» (primary, lg) и «I already have an account» (ghost) |

Фон: узор `idle` с фокусом на Buddy, два 3D-облака с дрейфом. Одна primary-кнопка. Весь текст дублирует реплики (пузыри декоративны).

## 3. Знакомство с приложением (Onboarding)

Четыре слайда, один смысл на слайд. Пагинация из квадратиков вместо кружков: активный растягивается в пилюлю 28px.

| Слайд | Маскот | Заголовок | Объекты |
| --- | --- | --- | --- |
| 1 | Leafy | Start small | sparkle, leaf |
| 2 | Sunny | Track what matters | water-glass, bike, moon |
| 3 | Buddy Streak | Celebrate every win | heart, sparkle |
| 4 | Dawn | Never miss a moment | calendar, sparkle |

**Переход.** Слайд сдвигается за `dur-page` (480ms) с `ease-emphasized`. Арт отстаёт на 70px и движется 1.3 длительности (параллакс). Текст появляется с задержкой 160ms и подъёмом 18px. Квадрат пагинации растёт 240ms с пружиной. На последнем слайде срабатывает `Buddy.burst`, «Skip» скрывается, у кнопки пропадает стрелка и подпись меняется на «Get started».

**Управление.** В превью работают «Next» и «Skip» и автопереход. В продукте добавьте свайп влево и вправо, клавиши ← и →, системный жест «назад» возвращает на слайд назад. Разрешение на уведомления просим на слайде 4 по нажатию, не при запуске.

## 4. Загрузка экрана (Skeleton)

`Buddy.LoadingScreen()`: серые блоки точно по форме главного экрана (шапка, три плитки, карточка прогресса, три строки) с бегущим бликом `bd-shimmer` (1.4 секунды, linear). Снизу сонный Sunny качается и подписывает «Loading your day…».

Правила: показывать скелет только если данные грузятся дольше 300ms; блоки того же размера и радиуса, что настоящие; не больше одного экрана скелета.

## 5. Лоадеры

| Вид | Код | Применение |
| --- | --- | --- |
| Squares | `Buddy.Loader({ kind: 'squares' })` | Заставка, ожидание ответа. Пять квадратиков по очереди растут и теплеют |
| Bar | `kind: 'bar'` | Загрузка файла, длительные операции |
| Orbit | `kind: 'orbit'` | Короткое ожидание внутри кнопки или карточки |

Подпись `label` пишется словами («Loading», «Saving»). Лоадер внутри кнопки заменяет подпись, кнопка не меняет ширину.

## 6. Доступность и движение

- `prefers-reduced-motion` и `data-motion="off"`: падение, облака и буквы появляются без движения (прозрачность 0 → 1 за 150ms), онбординг переключается без параллакса, узор рисует один кадр.
- Все состояния озвучиваются `role="status"` (лоадер) и `aria-hidden` у неактивных слайдов.
- Каждый экран можно пропустить: Splash не блокирует, Welcome ведёт к входу, у Onboarding есть «Skip».
- Контраст текста на градиенте `bd-grad-wash` не ниже 4.5:1 (`text-primary`, `text-muted`).
