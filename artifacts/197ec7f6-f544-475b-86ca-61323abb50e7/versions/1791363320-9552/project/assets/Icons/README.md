47 линейных иконок на сетке 24 × 24: штрих 2px, круглые окончания и соединения, безопасное поле 2px.

**Чернила.** Все SVG одноцветные, штрих `#26215F` (`violet-900`). Файл через `<img>` нельзя перекрасить: для кода используйте inline-вариант `Buddy.icon(name)` из `components/bundle.js` (красится через `currentColor`), для Figma замените цвет штриха. Разметка всех иконок собрана в `icons.json` (имя → внутренние элементы SVG): это единственный источник, из него собираются и файлы, и бандл.

**Применение.** Размеры 16, 20, 24, 32px (`size-icon-sm … xl`). В таб-баре активная иконка закрашивается на 16%. Группы и правила: компонент `Icons`.

Добавлено: `scan` (рамка-видоискатель с линией сканирования) для функции «Сканер».
