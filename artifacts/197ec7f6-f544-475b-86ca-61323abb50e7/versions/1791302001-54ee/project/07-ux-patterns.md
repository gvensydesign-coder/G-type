# UX-сценарии и паттерны

## Идея продукта

Приложение-друг, которое помогает выстроить маленькие ежедневные привычки: вода, сон, движение, дневник. Мотивация строится на тепле и прогрессе, а не на давлении. Маскот делает цифры эмоциональными, ассистент помогает начать.

## Карта экранов

```
Вход (Get started) → Онбординг с ассистентом (Hello…) → Главная (Home)
                                                      ├─ Трекер (Tracker): серия, сон, тренировки, метрики
                                                      ├─ Привычки (Habits): список, добавление
                                                      └─ Настройки (Settings)
Чат с ассистентом доступен с Главной (кнопка и подсказки)
Каталог помощников (Discover) — веб и раздел внутри приложения
```

## Основные сценарии

### 1. Вход и первое знакомство
1. Экран входа: три будильника, «Get started», две кнопки (Apple, Google). Юридический текст мелко. Основное действие одно: выбрать способ входа.
2. Экран ассистента: «Hello, How can I help you?». Подсказки (Habit Tips, Set-up goals, Schedule) убирают страх чистого листа. Поле внизу в зоне большого пальца.
3. После цели ассистент предлагает первую привычку с самым маленьким шагом («Let's start small!»).

### 2. Ежедневная проверка (10 секунд)
Главная показывает приоритеты сверху вниз: приветствие → три метрики дня → прогресс «3/5» с подсказкой «Next: Move 20 mins» → список привычек. Пользователь отмечает пункт: круг подпрыгивает, появляются конфетти, прогресс на карточке увеличивается.

### 3. Серия
Трекер показывает серию, неделю и итог дня. Правила: серия растёт при выполнении хотя бы одной привычки; прерывание подаётся мягко (Buddy sleepy, «Let's start again»), без красного и без счётчика потерь.

### 4. Диалог с ассистентом
Подсказки-чипы → ответ в пузыре → быстрые действия (добавить привычку, поставить напоминание). Фотографии и файлы прикрепляются скрепкой и камерой.

### 5. Каталог помощников
Фильтры по категориям (All Agents, Sleep, Fitness…), карточки с обложкой и автором. Открытие карточки ведёт на экран установки.

| Экран | Главное | Второе | Третье |

## Состояния

| Состояние | Что показываем |
| --- | --- |
| Пусто (нет привычек) | Sunny happy, заголовок «No habits yet», кнопка «Add habit», подсказка с примерами |
| Загрузка | `bd-skeleton` по форме будущих блоков (плитки, строки), без спиннеров |
| Ошибка сети | Баннер danger с иконкой и инструкцией + Sunny sleepy, кнопка «Try again» |
| Успех | toast «Habit saved» на 4 секунды, `Buddy.burst` при цели дня |
| Офлайн | Баннер info «You're offline. Changes sync later» |
| Достижение | Buddy streak, `title-lg`, конфетти, одна кнопка «Continue» |

## Голос и тексты

| Ситуация | Пишем | Не пишем |
| --- | --- | --- |
| Приветствие | «Hey, Lukman» · «Ready for a good day?» | «Добро пожаловать в приложение» |
| Старт | «Let's start small!» | «Начните выполнять цели» |
| Прогресс | «2 habits left» · «Next: Move 20 mins» | «Выполнено 60%» |
| Серия | «4 Days Streak» · «Rise and Good» | «Не потеряйте серию!» |
| Прерванная серия | «Let's start again» | «Вы потеряли серию» |
| Ошибка | «Could not sync. Check your connection and try again.» | «Ошибка 500» |
| Пустое состояние | «No habits yet. Add your first one.» | «Данных нет» |
| Кнопки | «Add habit», «Continue», «Try again» | «OK», «Submit» |

Правила: заголовок до пяти слов, глагол в начале у действий, одно главное сообщение на экран, числа с единицей.

## Геймификация без давления

- Награда за действие, не за идеальность: хотя бы одна привычка в день продлевает серию.
- Нет рейтингов и сравнения с другими по умолчанию.
- Нет штрафов, красных предупреждений и «обнуления».
- Празднуем малое: конфетти на каждую отметку допустимо, на цель дня усиливаем.
- Пользователь управляет интенсивностью: напоминания и анимации отключаются в настройках (`data-motion="off"`).

## Доступность в сценариях

- Все пути выполнимы без цвета: статусы имеют слова и иконки.
- Отметка привычки имеет роль `checkbox`, прогресс `progressbar` со значениями, таб-бар `aria-current`.
- Динамические изменения (прогресс, toast) озвучиваются через `role="status"`.
- Цели касания не меньше 44px, расстояние между ними 8px.
- Весь интерфейс масштабируется до 200% шрифта без обрезки.

## Экраны-эталоны

В разделе компонентов «Screens» собраны эталонные сборки: `ScreenHome`, `ScreenTracker`, `ScreenChat`, `ScreenAuth`, `ScreenDiscover`. Каждая показана в светлой и тёмной теме и целиком собирается из компонентов библиотеки.
