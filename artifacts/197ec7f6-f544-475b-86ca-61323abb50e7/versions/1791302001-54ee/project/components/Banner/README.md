Встроенное сообщение внутри экрана: иконка, заголовок и короткое пояснение на мягкой заливке статуса.

```js
Buddy.Banner({ tone: 'warning', title: 'Streak at risk', text: 'Finish one habit before midnight.' })
```

| Тон | Иконка | Роль |
| --- | --- | --- |
| info | `info` | `status` |
| success | `check-circle` | `status` |
| warning | `warning` | `status` |
| danger | `warning` | `alert` |

**Правила.**
- Заголовок называет событие, пояснение говорит, что делать дальше. Без извинений и без «Ошибка!».
- Иконка и заголовок обязательны: цвет фона один не различает статусы.
- Текст `text-primary`/`text-secondary` на `*-soft` (4.5:1 в обеих темах), иконка цвета статуса.
- Не более одного баннера на экран. Временные сообщения («Habit saved») показывайте как toast на `z-toast` и убирайте через 4 секунды.
