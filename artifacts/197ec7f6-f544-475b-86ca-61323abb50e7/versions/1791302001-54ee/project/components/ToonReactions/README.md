Реакции 3D-маскота на действия человека: нажатие, касание рядом, прокрутка ленты и настроение чата.

**Нажатие на зверя.** `Buddy.Toon.mount(host, kind)` сам вешает обработчик: случайный клип из `Buddy.Toon.taps` (`happy`, `laugh`, `surprise`, `bounce`, `nod_yes`, `shy`, `dance`, `sniff`), пружина `bdToonPop` 450ms и четыре сердечка `bdToonFx`. Выключается опцией `{ tap: false }`.

**Касание рядом.** `Buddy.Toon.gaze(api, host, clientX, clientY)`: взгляд на точку и моргание, через 1.3 с взгляд отпускается.

**Прокрутка ленты.** Взгляд идёт за направлением (`lookAt(sin(top / 90) * .35, dir * min(1, .35 + |dy| / 40))`), голова плавно наклоняется: целевой `pitch = .04 - dy * .012` (в пределах ±.32), `yaw = sin(top / 140) * .28`, инерция `0.14` за кадр через `requestAnimationFrame`. Рывок больше 70px вызывает `surprise`. Реакцию не перебивать, пока идёт клип.

**Настроение.** Ассистент думает: `play('curious')`; успех: `play('happy')`; иначе `auto()`.

Все реакции отключаются при `prefers-reduced-motion`: остаётся плоская иллюстрация.
