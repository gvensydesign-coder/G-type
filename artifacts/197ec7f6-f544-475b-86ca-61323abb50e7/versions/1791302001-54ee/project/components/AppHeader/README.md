Шапка экрана на градиенте `hero-from → hero-to`: действия, приветствие или заголовок, реплика и маскот.

```js
Buddy.AppHeader({ leading: 'menu', tools: 'home', bubble: "Let's start small!", title: 'Hey, Lukman', sub: 'Ready for a good day?', large: true, mascot: 'leafy-umbrella' })
Buddy.AppHeader({ title: 'My Habits Tracker', inlineTitle: true, tools: 'share' })
```

**Две схемы.** Приветственная: верхний ряд (меню, группа колокольчик + поиск, реплика справа), под ним `display-lg` приветствие и подзаголовок, маскот справа. Экранная: заголовок `title-xl` слева, группа действий справа.

**Контент поверх шапки.** Плитки и карточки идут через параметр `html` и перекрывают край. Ниже шапки идёт лист (`bd-sheet`) с радиусом `radius-3xl` вверху.

**Правила.**
- Текст на шапке только `text-on-hero` и `text-on-hero-muted`, ставьте его в верхней половине градиента, где фон темнее.
- Не больше двух действий справа и одного слева.
- Статус-бар системы окрашивается в `text-on-hero`.
- Тёмная тема: градиент уходит в `violet-800 → violet-900`, структура не меняется.
