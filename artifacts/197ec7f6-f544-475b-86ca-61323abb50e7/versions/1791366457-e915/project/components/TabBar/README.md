Плавающий стеклянный таб-бар: капсула 60px с полупрозрачностью 78% и размытием 28px, контент просвечивает, поэтому бар визуально занимает меньше места.

```js
Buddy.TabBar({ current: 'home' })   // по умолчанию Home, Tracker, Habits, Settings
Buddy.TabBar({ items: [{ id: 'profile', icon: 'user', label: 'Profile' }, …], current: 'profile' })
```

**Вкладка.** 48px, иконка 22px над подписью `label-sm`. Активная поднимается на `glass-active` с верхним бликом, иконка закрашивается на 16%, при переключении делает pop. Неактивная `text-secondary` (светлая тема) и `text-primary` с приглушённой иконкой (тёмная).

**Стекло.** `glass-bg` + `blur-lg` + `glass-saturate`, кромка `glass-border`, тень `shadow-glass`. Без поддержки `backdrop-filter` бар непрозрачный (`bg-surface-sunken`).

**Правила.**
- От трёх до пяти вкладок. Подпись всегда видна. Активная вкладка `aria-current="page"`.
- Бар на `z-tabbar`, от краёв 12px, от низа 14px. Контент прокручивается под ним, нижний запас листа 104px.
- Не ставьте под бар белые плашки и облака в тёмной теме без запаса контраста. Подробнее: раздел «Стекло и размытие».
- Жёлтые и оранжевые акценты на вкладках не используются: навигация нейтральна.
