Чип-капсула: быстрая подсказка с иконкой-плиткой или фильтр категории.

**Подсказка** (`Buddy.Chip({ icon, tone, label })`): 44px, слева цветная плитка 28px (`bd-tile--sm`), справа подпись `label-md`. Нажатие отправляет текст в чат или запускает сценарий («Habit Tips», «Set-up goals», «Schedule»). Ряд подсказок прокручивается по горизонтали и обрезается у правого края: так видно, что есть ещё.

**Фильтр** (`Buddy.Chip({ filter: true, label, pressed })`): 40px, без иконки. Активный чип инвертирован (`bg-inverse` + `text-inverse`), остальные на `bg-surface` с контуром `border-subtle`. Состояние хранится в `aria-pressed`.

**Тона плитки.** Закрепляйте цвет за смыслом: `yellow` советы, `pink` цели, `green` расписание и рост, `sky` вода, `orange` энергия. Тон не должен быть единственным носителем смысла: подпись обязательна.

**Правила.**
- Подпись до трёх слов. Фильтр «All» всегда первый и активен по умолчанию.
- Между чипами `space-2` (8px). Не выстраивайте больше одного ряда подсказок.
- Фокус клавиатуры показывает `ring-focus`.
