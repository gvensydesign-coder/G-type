Десять маскотов в многоцветном SVG: Buddy (`buddy-happy`, `buddy-streak`, `buddy-sleepy`), Sunny (`sunny-happy`, `sunny-sleepy`), Leafy (`leafy-umbrella`), будильники Zuzu, Dawn, Nox и лапы `paws-heart`.

Цвета фиксированные и не зависят от темы: файлы подходят для `<img>` на светлом и тёмном фоне. Размер по умолчанию 160 × 160 (`paws-heart` 240 × 200). Роли, настроения и правила применения: компонент `Mascots` и раздел «Иллюстрации и маскоты».
