Виджеты домашнего экрана и экрана блокировки: семь видов в трёх размерах.

```js
Buddy.Widget({ kind: 'streak' })      // S 158 × 158
Buddy.Widget({ kind: 'progress' })    // M 338 × 158, маскот выходит за верхний край
Buddy.Widget({ kind: 'habits' })      // L 338 × 354, список с отметками
Buddy.LockWidget({ type: 'circle', pct: 60, icon: 'flame' })
```

| Вид | Размер | Назначение |
| --- | --- | --- |
| `streak`, `water`, `mascot` | S | Одна метрика или реплика маскота |
| `progress`, `sleep`, `quick` | M | Прогресс дня, сон, быстрое добавление |
| `habits` | L | Список привычек |
| `LockWidget` circle, rect, inline | 72, 160 × 72, строка | Кольцо, полоса, фраза |

**Правила.** Один смысл на виджет. Размеры и сетка для iPhone 390pt (поля 26, зазор 22), на Android принимается ближайшая ячейка. Радиус `radius-widget`. Виджет с выходом маскота оставляет сверху 22pt. Нажатие открывает экран, отметка в `habits` меняет данные без открытия. Таблица размеров, обновление и тёмный режим: раздел «Виджеты, уведомления и иконка приложения».
