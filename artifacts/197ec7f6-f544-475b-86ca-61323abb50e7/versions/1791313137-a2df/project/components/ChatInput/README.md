Поле ввода сообщения ассистенту: карточка 24px с мягкой градиентной обводкой, подсказка, строка действий снизу.

**Строение.** Внешняя оболочка `bd-chat` (2px градиент `violet-300 → pink-300 → orange-300`, тень `shadow-md`), внутри `bd-chat__inner` на `bg-surface`: многострочное поле `body-lg`, ниже ряд `[скрепка] [камера] ········ [отправить]`.

```js
Buddy.ChatInput({ placeholder: 'Ask anything ...' })
```

**Что передаёт потребитель.** Обработчики вложения, камеры и отправки. Скрытый `label` уже включён для скринридера.

**Правила.**
- Подсказка короткая и открытая: «Ask anything ...», «Спросите что угодно».
- Кнопка отправки инвертирована (`bd-iconbtn--send`), активна только когда есть текст.
- При фокусе внутри добавляется `ring-focus`, градиентная обводка остаётся.
- Поле прилипает к низу экрана с отступом `space-6`, над ним ряд чипов-подсказок через `space-4`.
- Фон под полем: `bd-grad-wash` (лавандовое утро → персиковый закат), чтобы обводка читалась.
