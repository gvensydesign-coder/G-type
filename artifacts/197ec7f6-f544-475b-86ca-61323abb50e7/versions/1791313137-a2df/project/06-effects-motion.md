# Эффекты и анимации

## Тени и свечения

| Токен | Значение (светлая) | Где |
| --- | --- | --- |
| `shadow-xs` | `0 1px 2px rgba(60,40,140,.06)` | чипы |
| `shadow-sm` | `0 2px 8px rgba(60,40,140,.08), 0 1px 2px rgba(60,40,140,.04)` | строки, карточки |
| `shadow-md` | `0 8px 24px rgba(60,40,140,.12)` | плитки, поле чата, таб-бар |
| `shadow-lg` | `0 16px 40px rgba(60,40,140,.16)` | hero-карточка, шторка |
| `shadow-brand` | `0 8px 20px rgba(106,89,216,.38)` | главная кнопка |
| `shadow-orange` | `0 6px 16px rgba(255,132,38,.36)` | активный сегмент |
| `shadow-glow-streak` | `0 0 24px rgba(242,74,116,.45)` | сегодня в серии |
| `shadow-inset-top` | `inset 0 1px 0 rgba(255,255,255,.8)` | блик на приподнятом элементе |
| `shadow-pressed` | `inset 0 2px 4px rgba(60,40,140,.14)` | нажатая кнопка-иконка |
| `ring-focus` | `0 0 0 2px #fff, 0 0 0 4px #6A59D8` | фокус клавиатуры |

Правила: не складывайте больше одной тени + одного блика на элемент; в тёмной теме значения заменены на чёрные и контур `border-subtle`; свечение только у главного действия и у живых состояний.

## Стекло (Glass)

`background: rgba(255,255,255,.22)` (в тёмной .14) + `backdrop-filter: blur(12px)`. Только поверх градиента шапки и только для кнопок-иконок и их групп (`bd-iconbtn--glass`, `bd-pill-group`). Текст на стекле не ставится: контраст не гарантирован.

## Скругления и вложение

Шкала `radius-xs 6 · sm 10 · md 14 · lg 18 · xl 24 · 2xl 28 · 3xl 36 · pill`. Вложенный радиус = родительский − отступ: обложка карточки агента (внешний 24, отступ 8) = 16. Капсулы только у интерактивных элементов небольшой высоты.

## Принципы движения

1. **Объясняет, а не украшает.** Движение показывает причину и следствие: отметил, значит, круг подпрыгнул и появились конфетти.
2. **Живой, но не отвлекающий.** Постоянно двигается только маскот в покое. Остальное реагирует на действие.
3. **Пружина для радости.** `ease-bounce` только для успеха, награды, переключателей. Ошибка и удаление спокойные.
4. **Быстро.** Отклик на нажатие до 100ms, остальное до 400ms. Праздник до 700ms.
5. **Уважаем настройки.** `prefers-reduced-motion` и `data-motion="off"` убирают движение.

## Переходы между экранами

Эталон плавности: нижний таб-бар и раскрытие поиска на главной на весь экран. Остальные переходы подгоняются под него.

1. **Интерфейс не мигает.** Смена страницы: плавное исчезновение старого экрана (ghost-копия поверх, 320ms) и поэтапное появление нового. Смена состояния на той же странице: ничего не пересоздаётся, меняются только отличающиеся узлы.
2. **Не перезагружаем то, что не менялось.** Нажатие на тег, переключатель или сортировку не должно сбрасывать прокрутку, фокус в поле поиска, анимацию зверя и картинки.
3. **Лесенка один раз.** Класс `pd-enter` снимается через секунду после появления страницы, поэтому лесенка не проигрывается заново при каждом перерисовывании.
4. **Заливка `backwards`, не `both`.** `both` удерживает конечный кадр и блокирует последующие `transform` (нажатие, hover).
5. **Движение выключается.** `prefers-reduced-motion` отключает призраков, лесенки, ripple и сердечки; `Buddy.Toon.mount` не запускает зверя и оставляет плоскую иллюстрацию.

## Тактильный отклик (для мобильных приложений)

Лёгкий импульс на отметку привычки, «успех» на выполнение цели дня, ничего на обычные нажатия. Каждый импульс сопровождается визуальной реакцией, звук необязателен и выключен по умолчанию.

## Доступность движения

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .001ms !important; animation-iteration-count: 1 !important; transition-duration: .001ms !important; }
}
```

В `bundle.css` правило уже есть. Так же работает атрибут `data-motion="off"` на `<html>`. `Buddy.countUp` при reduced-motion сразу показывает итог.
