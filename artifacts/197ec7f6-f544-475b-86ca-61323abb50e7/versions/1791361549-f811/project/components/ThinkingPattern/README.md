Живой фон чата: сетка квадратиков, которая меняется вместе с состоянием ассистента (покой, раздумье, поиск, ответ, успех, сон).

```js
const pat = Buddy.Pattern.mount(hostEl, { focus: { x: 0.5, y: 0.3 } });
pat.set('searching');
statusEl.innerHTML = Buddy.ThinkingIndicator({ label: 'Searching…' });
```

**Что передаёт потребитель.** Контейнер с `position: relative` (узор заполняет его целиком), фокус в долях размера контейнера (центр маскота), вызов `set(state)` при смене стадии работы ассистента и текстовый статус рядом.

| Состояние | Движение |
| --- | --- |
| `idle` | дыхание полутона, редкие искры |
| `thinking` | кольца расходятся от маскота |
| `searching` | диагональный луч, находки вспыхивают |
| `answering` | колонки падают, как набор текста |
| `success` | одна зелёная волна, возврат в `idle` |
| `sleep` | приглушённо, офлайн или ошибка |

**Токены.** Цвета `pattern-cool`, `pattern-warm`, `pattern-ok`; сетка `pattern-pitch`, `pattern-cell`.

**Правила.** Только фон чата и пустых экранов, один слой на экран. Слой лежит под контентом. Состояние всегда дублируется текстом (`ThinkingIndicator`, `role="status"`). При reduced-motion рисуется статичный кадр. Ошибки не красим в красный. Полные правила: раздел «Фирменные приёмы».
