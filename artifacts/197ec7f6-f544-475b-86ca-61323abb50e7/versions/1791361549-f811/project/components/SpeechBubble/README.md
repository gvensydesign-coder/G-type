Реплика маскота: капсула на `bg-surface` с двумя точками-хвостиком, направленными к персонажу.

```js
Buddy.SpeechBubble({ text: "Let's start small!" })
```

**Анимация.** `bd-bubble`: появление за `dur-slow` с `ease-bounce` из масштаба 0.7, точка отсчёта у хвоста.

**Правила.**
- Одна короткая фраза (до пяти слов), дружелюбная, без восклицания в серьёзных состояниях.
- Реплика не несёт обязательной информации: всё важное дублируется в основном интерфейсе.
- Поверх градиента шапки пузырь белый (`bg-surface`) и читается 4.5:1 в обеих темах. Полупрозрачные пузыри запрещены для текста.
- Говорит всегда ближайший маскот: Leafy в шапке главной, Buddy на hero-карточке.
