Диалог с ассистентом: сообщения, набор текста, шаги поиска, карточка действия и стеклянный композер.

```js
Buddy.Message({ role: 'buddy', text: '…', extra: Buddy.MessageCard({ … }), time: '9:40' })
Buddy.Message({ role: 'user', text: '…' })
Buddy.ToolCall({ state: 'done', title: 'Found 3 ideas', sources: ['telegram', 'youtube'] })
Buddy.Typing()
Buddy.Composer({ placeholder: 'Message Buddy' })
```

**Что передаёт потребитель.** Роль и текст сообщения, время (у последнего в группе), состояние шага поиска, обработчики композера. Фон диалога `bd-grad-wash` и узор `Buddy.Pattern` в состоянии, совпадающем со статусом в шапке.

**Правила.** Ассистент слева на `bg-surface` (радиус 20/20/20/6), пользователь справа на `brand` (20/20/6/20). Пузырь до 90% ширины. Поиск показывает источники плитками 20px. Композер стеклянный (`blur-md`), над ним строка подсказок. Ошибка отправки сообщается под пузырём словами и иконкой. Полная анатомия: раздел «Экраны: диалог, профиль, уведомления, инсайты».
