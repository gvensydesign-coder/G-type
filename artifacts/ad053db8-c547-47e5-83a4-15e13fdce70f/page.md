## Вердикт

Визуальная система цельная, в обеих темах чистая, критичных поломок раскладки нет. Слабее всего «второй уровень»: пустые состояния, помощь по месту, обратная связь и мобильный редактор. В редакторе не хватает слоя навигации: нет названия шрифта в шапке, горячих клавиш, подписей у иконок.

Аудит сделан на версии 94: 1440 светлая и 390 тёмная по всем основным экранам, остальное выборочно. Шрифт Onest в песочнице не грузится, это не считалось ошибкой.

**Главное решение перед слиянием прототипа.** В сервисе карточки «Лаборатории» с 3D-иллюстрациями и вырезом со стрелкой, в прототипе — серые иконки в плашках. Нужен один язык. Моё предложение: главные входы остаются карточками с иллюстрациями (новая «С листа бумаги» тоже), внутри маршрута «Свой шрифт» — компактные плитки.

**Что из аудита противоречит вашим решениям** (оставляю как есть, если не скажете иначе):

- Агент предлагает сделать «Читать» в уроках чёрной. Вы выбрали её красной главной кнопкой — не меняю.
- Красную стрелку в вырезе карточек агент предлагает сделать нейтральной. Это утверждённый элемент (вы брали его образцом для крестика) — решать вам.
- Разрезанная карточка карусели «Популярные шрифты» — сознательный приём, но нарушает правило «ничего не обрезано». Предлагаю целое число карточек.

## Что выбивается или выглядит слишком просто

1. **Три разных пустых состояния.** В «Избранном» 3D-иллюстрация, в «Подборках» серые заглушки, в «Черновиках» только текст. Привести к одному шаблону.
2. **Красный там, где его не должно быть:** ползунки и флажки в «Проверке» и меню скачивания, красный значок на аватаре, точка у логотипа. Сделать чёрными по правилу «красный только для главного и ошибок» («Читать» и стрелки вырезов — см. вердикт).
3. **Залипшая подсказка «Профиль»** после клика по боковой панели перекрывает кнопку «Создать подборку». Это настоящая ошибка.
4. **Шапка профиля:** заглушка аватара, «Добавить ссылку» пунктиром, а в блоке «Создать» три разных стиля действий в одном ряду. Выглядит недоделанным.
5. **«Свой шрифт из файлов»:** сетка из сотни пустых пунктирных ячеек с кодами U+0041. Нет большой зоны «Перетащите SVG сюда», примера имён файлов и причины, почему «Скачать» серая.
6. **Окно «Поделиться»:** постер смещён вниз, сверху пустая полоса около 100 px, толстая рамка у поля названия, «Скачать WebM» без пояснения.
7. **Слайдер «Как это работает»:** кнопки внутри макета размером как настоящие, точки пагинации слишком бледные, стрелки без подписей.
8. **Карусель «Популярные шрифты»** обрезает крайнюю карточку («Лин…»).
9. **Список «Знаки» в редакторе:** последний ряд обрезан, нет признака прокрутки; в рисовании тот же список устроен иначе.
10. **Рисование:** панель «Сетка ячеек» может открыться пустой колонкой, нижний тулбар перекрывает низ холста (перепроверю во время переноса «Штриха»).
11. **Статья «Сообщества»:** узкая колонка с пустотой по бокам, нет оглавления и «Дальше по теме». У челленджа нет «Работ участников» и статуса «Вы участвуете».
12. **Карточка шрифта при наведении на телефоне** закрывает соседние и обрезана снизу, непонятно, как её закрыть.
13. **Кернинг:** несколько рядов плашек без иерархии, технический текст («мин. зазор 287 (безопасно от 42)») — перевести на простой язык, сохранив подробность.

Скриншоты аудита лежат в рабочей папке и войдут в архив проекта.

## Что добавить в дизайн-систему

| Компонент / правило | Спецификация в одну строку |
| --- | --- |
| Пустое состояние | три размера (в строке / в карточке / на страницу), иллюстрация или нейтральная пиктограмма, заголовок, одно пояснение, одна главная и одна вторая кнопка |
| Скелеты и загрузка | токены цвета и перелива 1,2 с (выключается при «меньше движения»), шаблоны для карточки шрифта, строки списка и холста |
| Подсказки и всплывающие панели | задержка 400 / 90 мс, скрытие по клику и при смене экрана, до 2 строк, вариант с клавишей, поведение на тач-экране |
| Горячие клавиши и палитра команд | компонент клавиши, окно по «?», поиск команд («Скачать», «Кернинг», «Тёмная тема») |
| Проверка полей форм | ошибка текстом под полем, иконка, фокус на первое ошибочное поле; правила для имени шрифта и файла |
| Сообщения и ошибки | что случилось, причина, действие («Повторить», «Отменить»); инфо / успех / ошибка; время показа; не перекрывает кнопки |
| Иконки | сетка 24 px, штрих 1,75, правила заливки в активном состоянии; свести два набора (боковая панель и тулбары холста) в один |
| Цвета для данных | последовательная и расходящаяся шкалы, «ошибка / замечание / чисто» без фирменного красного, контраст не ниже 3:1 в обеих темах (тепловая карта, метрики) |
| Плотность | «компактно / свободно»: высоты контролов и отступы для редактора на ноутбуке и планшете |
| Диалоги и нижние шторки | размеры, отступы, место кнопок, шторка на телефоне, фокус внутри, Esc, возврат фокуса («Поделиться», «Сохранить процесс?», тур сейчас разные) |
| Таблицы и списки данных | строка, чередование фона, закреплённый заголовок, сортировка, пустой результат (пары кернинга, метрики) |
| Доступность | одно кольцо фокуса, режим высокого контраста, ссылка «к содержанию», цель нажатия не меньше 44 px, описание холста для чтения с экрана |

## Быстрые победы

Небольшие правки с заметным эффектом. Можно сделать вместе с волной B, срок почти не меняется.

- [ ] Убрать красный с ползунков, флажков и значка на аватаре.
- [ ] Скрывать подсказку боковой панели по клику и при смене экрана.
- [ ] Одно кольцо фокуса на «Скачать шрифт».
- [ ] Название шрифта и текущий знак в шапке редактора.
- [ ] Вместо «Проверяем шрифт…» итог проверки.
- [ ] Окно «Поделиться»: убрать пустоту сверху, пояснить «Скачать WebM».
- [ ] Единый шаблон пустых «Черновиков» и «Подборок» с иллюстрацией как в «Избранном».
- [ ] Карусель с целым числом карточек; подписи у стрелок слайдера.

## Что не проверено

Агент не дошёл до тепловой карты, пера и подложки, «Ячеек» с активным инструментом, ошибок загрузки и диалога «Сохранить процесс?». Тепловая карта и подложка уже прошли отдельную проверку дизайна в версии 94. Скриншоты одобренного прототипа смотрелись только на главной.
