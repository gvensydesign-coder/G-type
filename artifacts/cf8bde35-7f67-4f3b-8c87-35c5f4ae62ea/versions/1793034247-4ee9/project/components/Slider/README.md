Ползунок параметра: тонкая дорожка 4px, акцентный круглый бегунок 20px с кольцом.

## Что передаёт потребитель
```html
<div class="ctl"><label><span>Насыщенность</span><output>420</output></label><input type="range" aria-label="Насыщенность"></div>
```
Приложение выставляет `--lo` и `--hi` (процент заполнения) и обновляет `<output>`. Значение на пределе — `output.clamp` (цвет `--accent`).

## Правила
- Дорожка: `--track`, заполненная часть `--track-on`; бегунок `--accent` с кольцом `--ring` под цвет поверхности.
- Подпись слева, значение справа, шрифт 13px (`--fs-md`), числа табличные.
- Подпись — короткое существительное («Ширина»), без пояснений: подсказка живёт в `.tip`.
- Зона касания на телефоне не меньше 44px по высоте.
