# Данные о площадке

Факты, которые интерфейс показывает на главной и в справке. Считаются из кода: `FONT_META` и `FONTS` (`ui_lib_u1.js`, `core_all.js`), меню экспорта `#ex-list` (`template.html`), `VFX_ORDER`, `OTU.ROWS`, `FAM_W`, `LANG_DB`. Функция `platformInfo()` (`ui_ds_s1.js`) возвращает то же во время работы: подписи на главной берите из неё, не копируйте числа.

## Словарь тегов (`LIB_TAGS`)

- Классы: Гротески, Новые гротески, Геометрические, Рукописные, Готические, Древнерусские, Унциальные.
- Инструмент: Ширококонечное перо, Остроконечное перо, Связные, Ротунда, Устав, Модульные.
- Пропорции: Узкие, Нормальные, Широкие. Контраст: Неконтрастные.
- Назначение: Акцидентные, Экспериментальные.
- Набор: Базовый набор, Кириллица + латиница. Особенность: Вариативный.
- Плитки на главной: Гротески, Рукописные, Готические, Древнерусские, Акцидентные, Геометрические, Базовый набор, Вариативный.

## Форматы экспорта

| Подпись в меню | Код | Что получается |
|---|---|---|
| Шрифт .ttf | `ttf` | один файл для установки; пункт по умолчанию (`.pri`) |
| Для сайта .woff | `woff` | файл для подключения на сайте |
| Семейство .zip | `fam` | архив: все веса одним архивом |
| Вариативный .ttf | `vf` | один вариативный файл с осями |
| Образец .png | `png` | картинка-образец |

## Функции OpenType (`OTU.ROWS`)

| Тег | Подпись | Заметка |
|---|---|---|
| `smcp` | Капитель | строчные заменяются капителью |
| `c2sc` | Капитель из прописных | включают вместе с «Капителью» |
| `onum` | Минускульные цифры | цифры разной высоты |
| `tnum` | Табличные цифры | цифры одной ширины |
| `frac` | Дроби | 1/2 превращается в дробь |
| `sups` | Верхние индексы | как в м² |
| `subs` | Нижние индексы | как в H2O |
| `liga` | Лигатуры fi fl ff | только латиница; только Квадра и Линия |
| `salt` | Альтернаты | печатные формы рукописных букв |
| `swsh` | Росчерки | выходной и подводящий штрих |

Функция доступна, если в выбранной гарнитуре есть соответствующие знаки (`OTU.has`).

## Веса семейства (`FAM_W`)

Light 300, Regular 400, Bold 700, Black 900. У «Вашего шрифта» весов семейства нет.
