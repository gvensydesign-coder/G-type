Три поверхности: `.card` — плоская на фоне, `.surface` — плавающая белая, `.lcard` — карточка шрифта. Фирменный приём — карточка с вырезом в углу и круглой стрелкой.

## Карточка с вырезом (`.notchc`)
```html
<div class="lcard notchc">
  <span class="notch"><span class="nb go"><i class="ico i-arrow-r"></i></span></span>
  <!-- содержимое -->
</div>
```
- `.notch` 56px (`--nn`) вырезает верхний правый угол цветом подложки `--bg`; две вогнутые дуги радиусом `--nr` (18px) делают углы плавными.
- `.nb` — круглая стрелка 40px (`--nb`) с контуром `--ink`; при наведении карточки заливается чёрным; в выбранной карточке — акцентом.
- Цвет выреза обязан совпадать с цветом, на котором лежит карточка: в тёмной теме это `--bg`.

## Правила
- Радиус карточки `--r-lg` (22px), внутренний отступ `--s3`–`--s4`.
- Выбранная карточка: фон `--paper`, тень `--sh-2`, точка акцента у названия.
- Не вешайте на карточку цветную полосу слева; различие — тоном поверхности.
- Карточка целиком кликабельна, `role="link"`, видимый фокус.

## Угловая кнопка в вырезе
- Кнопка лежит в настоящем вырезе карточки, на фоне страницы, без видимой подложки. Карточка с вырезом не имеет собственного фона и тени: форму рисуют два слоя с маской (контур 1px `--cring` и заливка `--cbg`), поэтому контур и тень повторяют изгиб выреза.
- Превью внутри карточки режется той же формой. Состояния (наведение, выбрана) меняют `--cbg`, а не `background`.
- Нельзя имитировать вырез пятном цвета страницы поверх карточки с тенью: вокруг кнопки проступает квадратная подложка.
