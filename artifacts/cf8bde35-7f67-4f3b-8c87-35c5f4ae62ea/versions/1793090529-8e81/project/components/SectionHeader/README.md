`.sec-h` — малый заголовок секции, `.divider` — тонкая линия, `.empty` — пустое состояние.

## Заголовок секции
`<h4 class="sec-h">Оси</h4>`: 11px, прописными, трекинг .08em, цвет `--text-2`. Применять редко: в основном заголовки панелей — это `.pane-t`. Подпись — одно слово, без двоеточия.

## Разделитель
`<hr class="divider">` — 1px `--line`, отступ `--s3`. В меню отступ `--s1`.

## Пустое состояние
`.empty` на `--card`: иконка 44px `--text-2`, заголовок 20px жирный, одна строка пояснения, главная кнопка `.btn.pri`. Текст говорит, что делать дальше, а не что сломано.
