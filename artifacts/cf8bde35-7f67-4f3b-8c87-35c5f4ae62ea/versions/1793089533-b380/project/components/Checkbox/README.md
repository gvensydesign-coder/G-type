Флажок и радио (`.chk`) и переключатель (`.tgl`, 34×20).

## Что передаёт потребитель
`<label class="chk"><input type="checkbox"><span>Подпись</span></label>`; радио — тот же шаблон с `type="radio"` и общим `name`. Переключатель: `<label class="tgl"><input type="checkbox" role="switch"><span>…</span></label>`. Подпись обязательна и кликабельна.

## Правила
- Отмеченное состояние — `--accent-press` (белая галочка 4.69:1). Контур неотмеченного — `--g400`, 3:1 к фону.
- Флажок 20px, круглый, в стиле бренда; не меняйте на квадратный.
- Переключатель — для мгновенного действия, флажок — для выбора, применяемого позже.
- Выключенный элемент — 40%; фокус — кольцо акцента.
