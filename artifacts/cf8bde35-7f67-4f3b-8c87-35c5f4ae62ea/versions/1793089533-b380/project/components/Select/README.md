Выпадающий список `select.sel` и всплывающее меню `.menu` / `.xmenu` (меню «Скачать»).

## Что передаёт потребитель
- `select.sel` — обычный `<select>`, стрелка из `--chev` меняется с темой автоматически.
- `.menu` — набор `<button role="menuitem">`; текущий пункт `.on` (акцентная заливка `--accent-soft`, текст `--accent-text`). Разделитель — `.divider`.
- Позиционирование (абсолютное под кнопкой, закрытие по Esc и клику снаружи) — на стороне приложения.

## Правила
- Меню на `--paper` с тенью `--sh-3`, радиус `--r-md`; пункты 34px, радиус `--r-xs`.
- Названия форматов — расширение в конце: «Шрифт .ttf», «Для сайта .woff».
- Не более семи пунктов без разделителей.
