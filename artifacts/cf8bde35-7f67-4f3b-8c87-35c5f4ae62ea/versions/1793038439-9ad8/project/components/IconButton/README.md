Круглая кнопка только с иконкой: `.ibtn` на белой бумаге с волосяной обводкой, `.ibtn.sm` — 34px, `.tbtn` — плоская без обводки.

## Что передаёт потребитель
Иконка `<i class="ico i-имя">` (маска, цвет берётся из `currentColor`) и обязательный `aria-label` по-русски: подписи у кнопки нет.

## Правила
- Размер `--h-lg` (42px), на телефоне 44px и больше: зона касания не меньше 44px.
- Наведение инвертирует: фон `--ink`, значок `--on-ink`. Выключенная — 40%.
- Иконки одной линейной семьи, штрих 1.8; набор в README, раздел «Иконография».
- Не заменяйте подпись иконкой там, где действие неочевидно; добавьте `.tip`.

```html
<button class="ibtn" type="button" aria-label="Назад"><i class="ico i-undo"></i></button>
```
