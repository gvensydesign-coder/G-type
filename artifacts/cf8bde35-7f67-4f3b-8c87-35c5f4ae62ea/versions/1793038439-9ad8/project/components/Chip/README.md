Чип — фильтр или переключатель, тег — подпись на карточке, бейдж — счётчик.

## Что передаёт потребитель
- `.chip` — `<button>` с короткой подписью; выбранный получает `.on` и `aria-pressed="true"`.
- `.tag` — `<span>` с термином классификации ParaType («Гротески», «Ширококонечное перо»).
- `.badge` — число. `.badge.danger` — проблемы проверки (цвет `--danger`), `.badge.mute` — нейтральный счётчик.

## Правила
- Выбранный чип — чёрная таблетка `--ink`, не красная: красный остаётся за действием.
- `.chip.soft` — акцентный текст `--accent-text` на `--accent-soft`; для подсказок и «новое».
- Теги показывают не более трёх на карточке; названия — термины ParaType, без микроподписей.
- Размер текста не меньше 11px; бейдж не несёт смысл только цветом — рядом число или слово.
