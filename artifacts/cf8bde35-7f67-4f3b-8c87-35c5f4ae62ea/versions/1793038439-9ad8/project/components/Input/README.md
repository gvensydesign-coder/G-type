Поле ввода `.inp` (текст, число, `textarea.inp`) и поиск `.srch` с главной кнопкой внутри.

## Что передаёт потребитель
`<input class="inp">` с `aria-label` либо видимой подписью; для ошибки — `aria-invalid="true"` и текст ошибки рядом (цвет не единственный сигнал). Поиск: иконка `.i-search`, `<input>`, кнопка `.btn.pri`.

## Правила
- Заливка `--surface-2`, контур `--line`; при наведении `--line-strong`; фокус — внутреннее кольцо `--accent` 2px.
- Ошибка — `--danger`, не бренд-красный.
- Плейсхолдер — `--text-2`; он не заменяет подпись.
- `.srch.big` для главной (радиус `--r-lg`, шрифт 16px); в шапке — обычный `.srch`.
