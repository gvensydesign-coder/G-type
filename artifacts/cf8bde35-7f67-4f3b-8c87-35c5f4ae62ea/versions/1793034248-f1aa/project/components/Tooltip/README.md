Подсказка `.tip` и уведомление `toast()`.

## Подсказка
`<button class="tip" data-tip="Текст">`: чёрная плашка `--ink` с текстом `--on-ink` 12px над элементом, по наведению и фокусу, без задержки. У кнопок рейла (`.rb[data-tip]`) подпись справа, 13px, на фоне `--rail`.
- Подсказка дублирует `aria-label`, но не заменяет его. Существенная информация не может жить только в подсказке: на касании наведения нет.

## Уведомление
`toast('Шрифт сохранён')` — чёрная таблетка снизу по центру, тень `--sh-3`, появляется за 200ms и исчезает сама. Одна короткая фраза без точки; ошибки показывают в интерфейсе с `--danger`, а не тостом.
