Рейл — вертикальное иконочное меню слева, закреплённое у края окна (64px, `--rw`). Это единственная навигация между «Главная», «Библиотека», «Избранное», «Редактор».

## Разметка
`nav.rail` > `button.logo` («G» с красной точкой) + `.rpill` (группы кнопок) > `button.rb[data-tab][data-tip][aria-label]` с иконкой `<i class="ico i-…">`. Нижняя группа `.rpill.foot` прижата вниз: тема, подсказки, проект.

## Правила
- Фон `--rail` (#1C1C1E в светлой теме, #232328 в тёмной), значки `--on-rail`; активная кнопка — заливка `--rail-hi`, значок цвета рейла.
- Подпись — всплывающая подсказка `data-tip` справа от кнопки, показывается по наведению и фокусу; у каждой кнопки есть `aria-label`.
- Размер кнопки 52px (46px на низких экранах), иконка 24px; одиночная кнопка редактора — круглая 72px без таблетки.
- На телефоне (до 720px) рейл становится нижней таблеткой на всю ширину, логотип скрыт.
- Рейл не держит прокрутку и не содержит текста, кроме подсказок.
