Поле ввода `.inp` (текст, число, `textarea.inp`) и поиск `.srch` с главной кнопкой внутри.

## Что передаёт потребитель
`<input class="inp">` с `aria-label` либо видимой подписью; для ошибки — `aria-invalid="true"` и текст ошибки рядом (цвет не единственный сигнал). Поиск: иконка `.i-search`, `<input>`, кнопка `.btn.pri`.

## Правила
- Заливка `--surface-2`, контур `--line`; при наведении `--line-strong`; фокус — внутреннее кольцо `--accent` 2px.
- Ошибка — `--danger`, не бренд-красный.
- Плейсхолдер — `--text-2`; он не заменяет подпись.
- Все поля поиска (главная, библиотека, поиск параметров) — одна спецификация, эталон — поиск на главной: радиус `--r-field` (= `--r-pill`, полная пилюля), отступы `4px 4px 4px --s4`, поле 42px / `--fs-base`, кнопка «Найти» 46px, общая высота 54px. Варианты `.srch.big`, `.psearch` меняют только заливку под поверхность — никогда не радиус и не размеры.
- Фокус составного поля рисует обёртка (`:focus-within`) по всему периметру и только внутрь контура: `inset 0 0 0 2px --accent, inset 0 0 0 5px --focus`. Внутренний `<input>` без рамки и тени. Внешнее кольцо запрещено — родитель с `overflow` его обрежет.
