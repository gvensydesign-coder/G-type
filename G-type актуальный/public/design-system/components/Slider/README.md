Ползунок параметра: тонкая дорожка 4px, круглый бегунок 20px цвета `--ink`.

## Что передаёт потребитель
```html
<div class="ctl"><label><span>Насыщенность</span><output>420</output></label><input type="range" aria-label="Насыщенность"></div>
```
Приложение выставляет `--lo` и `--hi` (процент заполнения) и обновляет `<output>`. Значение на пределе — `output.clamp` цвета `--accent-text`.

## Правила
- Дорожка: `--track`, заполненная часть `--track-on`. Бегунок `--ink`.
- Подпись слева, значение справа. Подпись — короткое существительное («Ширина»).
- Зона касания на телефоне не меньше 44px по высоте.
