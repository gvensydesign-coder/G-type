Кнопка-«таблетка» для действий. Высота `--h-md` (34px), отступы `--s4`, шрифт 14px, радиус `--r-pill`.

## Когда использовать
- `.btn.pri` — одно главное действие в области экрана («Скачать», «Найти»). Фон `--accent-press`, белый текст 4.69:1.
- `.btn` — вторичные действия (белая бумага, контур `--line`).
- `.btn.ink` — тёмная кнопка для сильного, но не главного действия.
- `.btn.ghost` — третичное действие без рамки.
- `.btn.danger` — разрушающее действие: контур и текст `--danger`, не бренд-красный.
- `.btn.sm` — плотные панели (28px).

## Что передаёт потребитель
Текст (короткий глагол по-русски, без точки) и при необходимости иконка `<i class="ico i-…">` перед текстом. Состояние выключено — атрибут `disabled` (40% непрозрачности).

## Правила
- Не более одной `.btn.pri` на область экрана.
- Белый текст на обычном `--accent` ниже 20px жирным запрещён: контраст 3.5:1.
- Наведение меняет только фон; нажатие сдвигает на 1px вниз. Фокус — одно кольцо `--focus-ring` цвета `--ink` и нейтральный ореол `--focus`.

```html
<button class="btn pri" type="button">Скачать</button>
<button class="btn" type="button">Отмена</button>
```
