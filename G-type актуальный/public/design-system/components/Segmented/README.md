Сегментированный переключатель взаимоисключающих режимов: трек `--panel`, выбранный сегмент — чёрная таблетка (`.on`).

## Что передаёт потребитель
`<div class="seg" role="group" aria-label="…">` с 2–4 кнопками `<button>`; ровно одна с `.on`. Подписи — одно слово.

## Правила
- `.seg.light` — выбранный сегмент белый с тенью `--sh-2`, для переключателей поверх тёмного или цветного.
- Недоступный сегмент: класс `.dis` (38%), `aria-disabled`.
- Меняется только фон и цвет, без сдвигов; на телефоне высота сегмента 44px.

## Высота в ряду
Все контролы одного ряда — одной высоты (панель библиотеки: «Поддержка языков» = сегменты = 36px). Кнопка, у которой в одной теме нет видимой заливки, всё равно совпадает по высоте с соседями в другой теме.
