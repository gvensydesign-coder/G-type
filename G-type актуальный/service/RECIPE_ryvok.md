# Recipe: «Рывок» (Ryvok Display) v3 — black dense wide grotesk + horns that grow out of the stroke. core_ryvok_n4.js = ryvok_body.js + ryvok_tail.js (mk_ryvok.sh)

Reference (Japanese logotype lettering, style only): black monumental mass, slit counters, stroke ≈ gap, stroke ends flaring into sharp horns with one concave edge (foot of 青, bottom bar of 王, 春 horizontal), symmetric / perspective / slanted (東京未来) variants. Letterforms original, unicase (lowercase = caps; y = У form).
1. Base first (unchanged from v2): `rc`/`ch`/`hole`/`dg`, `st` (stem, angled entry cut), `bar`; stem 0.315 capH (Light/Regular/Bold/Black = .28/.315/.345/.375), bars = min(0.85 stem, 0.262 h), ring walls 1.1 stem, sb 14, slit counters.
2. Unique layer last: `K.wedge(a,b,T,n)` = horn polygon (op 'post'), base a→b = the stroke end (full bar thickness H for bar ends/tops, 0.16–0.34 h of the stem edge for feet), straight edge a→T, concave edge b→T via thickness tw+(w0−tw)(1−t)^kk, kk 1.6–2.4 (concave sweep), tip thickness tw 18–26 u. Base is pushed 0.32 stem into the stroke so horns are one silhouette with the glyph. No hairline spurs.
3. Direction: horns lie ALONG the baseline/bar. Tip offset `K.tipL/tipR`: left tips drop (≤ 0.075 h by default), right tips rise (0.07–0.12 h; more with sym), «Симметрия» lifts both (王). TL/TR = top-bar ends, straight upper edge rising ≤ 0.12 h, concave under-edge.
4. Placement per glyph by structure (≈ 60–70% of letters carry one): feet flare BL/BR (П Н Ш Ы Ь В Д …), bar ends SL/SR (Е Л Z S С Э З 2 5 J), diagonal feet BLe/BRe (А К Х Ж Л Я R), top sweep TL/TR (Т Г Б Е Ъ F Z 7). Rounds О 0 8 Ф Q and V W Y У carry none.
5. Params: cham, spk, fury, lean (drop), spkU/spkD/spkS, sym (right-side length + rise), persp, blade («Скорость»: left horns up to 0.72 h long, drop ×(1+3.6b) → long tapered diagonals as in 東京未来). Presets Прорыв / Симметрия / Скорость / Чистый.
6. Side allowances come from the BODY (0.8 L left, 0.95 L right of the horn + 6): horns hang into neighbour space; tips are 28–34 u. Proof hook `F.proof.hang` (ui_c.js) skips the «за поля» and «тесные поля» notes for ryvok only; real check = coll_n4.py (glyph ink overlap in the 4 test words = 0). Kerning classes unchanged.
7. Proof: foot flares reach 0.34 h, so stem-width sampling uses `F.proof.stemFy:[0.62,0.68]` (new per-font hook in ui_c.js computeProof, default [0.22,0.42] for all other fonts).
8. Limits `ryLim`: asc from Utop = upf(L)+4, desc from Dmax = dnf(L). Checks: proof holeK 0.02; stress 150×seeds 1,2,3 regular+italic and pres = 0; golden only ryvok lib md5 lines change.
