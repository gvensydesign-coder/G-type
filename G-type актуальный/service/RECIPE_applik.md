# Recipe: «Аппликация» (Applikatsiya Paper) — unicase display font of hand-cut paper pieces. core_applik.js = applik/{engine,build,glyphs,glyphs2,api,tail}.js (mk_applik.sh); stress: stress_applik.js; proof: t12p.py applik

Idea: children's paper collage. Every glyph is 2–6 polygonal pieces (strips, blobs, arcs; holes are pieces with a crooked oval hole) glued on top of each other; the host unions overlaps (csgUnion in finalGlyph, so TTF/deco outline/inline/shadow see ONE contour). Direction A «Ножницы» (straight scissor cuts) is the default; «Рваный край» (ctear 0..100) turns the same pieces into torn paper (B is a level, not a second font). Unicase: lowercase = caps at 0.86·capH, own cuts for а е ё о и н т с р к л м у (ALC), the rest reuse the capital recipe.
1. Pieces (build.js K.*): strip (4–6 gon, ends cut at ±blunt°), vs/hs (vertical/horizontal bar), arc/ring/blob/oring (10–13-gon bowls, crooked holes), dot, tri. Every piece is seeded by hash(glyph id | lc | seed | seedAdd) → mulberry32, so a glyph never changes with its neighbours or position (cache-friendly, stable for the same «Вариант»).
2. Host params (tail.js, keys prefixed c… because jit/lean/seed/… belong to other fonts): stem 106–232 (Насыщенность), ctear «Рваный край» 0–100 (def 0), cgap «Зазоры» 0–100 (def 0 = glued), clap «Нахлёст» 0–100 (strips extend both ends by lap·0.5·S), cpcs «Количество кусочков» 0–100 (aSplit: strips ≥ 300 u split into 2–3 segments, overlap 0.2w, small shift/rotation), csharp «Острота резов» (blunt = 20-18·sharp/100°), csoft «Мягкие резы» (aSoftK ≤ 1.6, soft ≤ .27 of S), cjit «Неровность», cscat «Разброс размера» (height ±10 %, width ±12 % scaled), clean «Разброс наклона» 0–10°, cbj «Скачет строка» (baseline coeff 0.07), cseed «Вариант» 0–99. tail.js maps them in apGen(p); sb is 0 inside (host adds p.sb 92; shape() x starts at 0, w = ink width).
3. Weights (capH 700): stem Light 114 / Regular 150 / Bold 192 / Black 226 (famParams scales by p.stem/150); WSCALE.applik 0.77 so Regular reads «Regular». Hidden: wdth capH xh asc desc hair and all other fonts' keys (F.params[k]=null; the other fonts get null for the c… keys).
4. Safety net (api.js aGet → aTopoOK): reference = same glyph at stem 150, jit/gap/tear/lap/pcs 0, same seed; check holes count, hole ≥ 0.005H², parts (reference … + gl-flagged end segments), no specks < 4500 u², thin ≤ 1.2 %, slit ≤ 70 (4 u raster). On failure rebuild along [[.7,1,1],[.45,1,.8],[.2,1,.6],[.45,0,.6],[.2,0,.4],[0,0,.2],[0,0,0],[0,0,0,.95],[0,0,0,.9],[0,0,0,.85]] = (jit, gap, tear, stem) factors; lap/pcs/soft/scat/sharp are pulled to 0/50 with the tear factor.
5. Host touches: core4.js `FONTS[CUR_FONT].deTiny` (F.deTiny=7) runs STK.deTiny twice after the union: joints of overlapping pieces leave 1–6 u edges which the proof lint «ступенька» flags. KERN_TABLE.applik = KERN_TABLE_BASE (class kerning measured from profiles). No VF (pieces have no interpolation-compatible topology, like Капля); no uniwidth. Latin shares Cyrillic constructions (LATSH: A B C E H K M O P T X Y→У); Latin-only: D F G I J L N Q R S U V W Z. Added U+2212 «−» (short bar).
6. Presets: Характер (Ножницы, Рваная бумага, Мозаика, Аккуратная, Малыш) + Край / Зазоры / Кусочки / Вес rows.
## Quality rules
- Lead fix (ш щ ц Ш Щ Ц): the base bar is inset (hs from a·.1 to W-b·.1) so it never overhangs the stems (reads as a letter, not an underline); checked in «съешь», «ромашка», «шишка щука».
- Counters: Ъ Ы № Q had pinholes/closed counters at stem ≥ 190: rings taller (Ъ .72H, Ы .67H, № ring .3–.8H), own lowercase ъ (ALC), Q tail starts at (.6W,.14H).
- Pieces must never float: every piece overlaps a neighbour (parts == reference), checked by the topology stress; gap > 0 splits only gl-flagged end pieces (F.proof.drops).
- Seed 0 is a legal but lively draw: lowercase height scatter ±15 % (х ш v reach 700+ at seed 0); lower «Разброс размера» for text sizes.
Stress: stress_applik.js (host-level, F.raw = aGet): every slider min/max (+tear), all-min/all-max, random combos, presets, family weights; 0 bad over seeds 1, 2 (100 combos × 79 glyphs) + presets. Standalone generator stress (collage_s1/stress.js, 27k builds) 0 bad.
Lessons: (1) host keys clash — grep PARAMS before naming a slider; (2) the generator should emit ink-width glyphs from x = 0 and let the host own sidebearings; (3) every new slider multiplies fallback cases: add the slider to the fallback chain (pull it to default with the same factor) and re-stress; (4) lint «ступенька» comes from unions, fix it once in the host (deTiny) not per glyph; (5) check weight naming by weightOf (WSCALE) before the first golden md5; (6) pinholes appear where a strip start sits inside a counter — start strips in the wall.
