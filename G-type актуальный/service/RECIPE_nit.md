# Recipe: «Нить» (Nit) — hand-drawn monoline, one round pen. core_nit.js = nit/{engine,skel,tail}.js (mk_nit.sh); stress: stress_nit.js; proof: t12p.py nit; e2e: tests/e2e_nit.py

Idea: one thin round-pen line IS the letter. Every glyph = 1–6 separate skeleton strokes that meet loosely like a felt-tip. Lowercase Cyrillic = wider, looser small caps of the same hand (1.18× wider, sb 0.15 cap); Latin lowercase = real forms (a b d e f g h k m n p q r t u + i j l, y) with ascender 1.07 cap and descender 0.25 cap. Default = poster-thin line (stem 19.6 u = 0.0265 cap). Approved design is frozen (user: «Меня все устраивает»); this recipe is the product integration.
Prototype/design history: scratchpad w82/N1 (nit.js round 2b, RECIPE_nit.md draft, approval sheets). Rejected earlier: closed ovals as one closed contour (too clean), uniform wobble by normals (broke corners), stem 0.03 default (too thick), gaps at default (misreads at 16 px).

## Pipeline (native in the product engine, not the traced TTF)
1. engine.js = the generator (port of nit.js, logic unchanged): glyph -> dense polylines with hand (per-stroke tilt, low-frequency wobble, radial wobble on ovals, width ±8 %), joins (free ends trimmed before snapping, snap to the nearest point of another stroke, overshoot/retract by «Стыки»), glyph-level lean ±4.5°, height ±6.5 %, baseline ±3.4 %, width ±7 %, optical spacing from a 12-band profile. Seeded by hash(char | seed): independent of neighbours and of the sliders (raising «Дрожь» scales the SAME hand).
2. skel.js (`nzSkel`): every polyline -> smooth skeleton strokes: kinks (> 48° over a 14 u window) split a stroke (round pen = round join), each smooth piece = cubic Hermite nodes by arc length (≈48 u apart), tangents from the local direction, a node is inserted where the fit deviates > 0.12 u. Dots = 2-node strokes (exact capsule). Width per stroke = node w.
3. tail.js (`nzContours`): host `skShape(skel, font, p)` with the round pen (rx = ry = S/2) -> offset + exact union + simplify (simpTol 0.3, no node budget). Holes smaller than (1.2 S)² are filled (slivers between near-parallel strokes; real counters are ≥ (2.6 S)²).
4. Safety net (`nzGet`, as applik/stolb): reference = same glyph/seed at default thickness and width, wob 0, join 40; the result must have the same number of parts and holes in the vector contours AND in a 2 u raster (parts 8-connected, holes ≥ (1.1 S)²), no vector hole < (1.1 S)², part ≥ 0.5 S². Otherwise rebuild along (wob ×0.8/0.6/0.4/0.2/0, then narrower ×0.9/0.8/0.7, then wider ×1.1/1.2, thinner ×0.9/0.8, join ≥ 25) and finally the reference hand at the user's thickness. Defaults (seed 1) never trigger it; with random seeds ≈ 1–3 % of glyphs do (a bar that would detach, an oval that would open, an A with a gap).
5. Geometry made S-aware (identical at the default S): dot height above letters ≥ 2.6 S, quote/ellipsis spacing ≥ 2.6/3.2 S, ° % № rings ≥ 1.5 S, # and % wider ≥ 5.6/6.2 S, Ф ≥ 5.4 S wide (two counters).
6. Host: fixed sidebearings (opt.fixed, sb = 0, opsp = 0; spacing comes from the generator), `track`, `space` (250), `slant` (italic = 10° shear, no cursive italic) stay host sliders. Shared forms are ONE glyph (A B C E H K M O P T X e o c x y = А В С Е Н К М О Р Т Х е о с х у; homo lane). Latin a and p are real hand forms: SKIP in homo.js.
7. Metrics (UPM 1000): cap 740, xh/small cap 480, asc 900, desc 260; hhea 921/−281 after the union; no VF (no interpolation-compatible topology: seeded hand), no uniwidth, kerning = host class kerning (KERN_TABLE.nit = base), GPOS kern exported.

## Parameters (own keys, prefix n; grep PARAMS before naming)
- nlw «Толщина линии» 2..80 (default 5): stem S = 740·(0.022 + 0.09·nlw/100) = 17.5…69.6 u. THE ONLY thickness of the font: host `stem` is derived from it (hidden slider), the «Характер» presets (Плакатная, Ровная, Живая, Узкая, Широкая) never contain it, the explicit «Толщина» chips (Нить 5, Тонкая 20, Средняя 40, Жирная 70) set it by the user's click, family weights are computed FROM the user's value (Light ×0.70, Regular ×1 = the user's value, Bold ×1.39, Black ×1.68), the single exports (TTF/OTF/WOFF) carry exactly the user's value. Saved in the project (`p.nlw`) like every slider. Weight name (weightOf) by stem/xh with WSCALE.nit 0.1296 so the default is Regular.
- nwd «Ширина» 0..100 (30): width ×0.75…1.6. nwob «Дрожь руки» 0..100 (80): 0 = clean mono skeleton. njn «Стыки» 0..100 (40): 0 meets with ≥ 0.4 S overshoot, 100 = overshoot up to 0.055 h; negative (gaps) removed: any visible gap detaches a bar or opens a bowl (prototype range −20..100 narrowed to 0..100 by the host stress). nseed «Вариант» 0..999 (1).
- Stress (host level, through the net): `stress_nit.js ext` (all slider min/max, 16 seeds, all pairs of extremes) 8350 glyph builds bad 0, `60 1` and `60 2` (random mixes, 10 020 builds each) bad 0, `pres` (presets + family weights) bad 0; raw generator failures without the net: ext 114, rnd 59–76, pres 10 (1 %). Limits narrowed from the first sweep: thickness 0..100 → 2..80 (at 100 № and % merge, at 0 a/6/W/O open at the thin end); join −20..100 → 0..100.
- Raw failure rate of the generator without the net (stress_nit.js sweep, 4 seeds × 167 glyphs): nlw 0 3.4 %, 2 2.2 %, 4 1.2 %, 8 1.0 %, 40 0.3 %, 60 0.6 %, 70 1.2 %, 80 1.8 %, 100 3.7 %; nwd 9–13 per 668; nwob 0 → 0, 60 → 8, 90 → 14, 100 → 18; the rest is seed hand variance. Host (through the net) must be 0 bad.

## Rules / decisions
- Л Д л д: short hooked top, concave outward-splaying left leg (must not read as П; e2e checks the 20×20 IoU against П/п < 0.6). 6 ≠ б (б has a curved flag and ascends). Dots/ticks are pen dabs (the only intended ink islands). Й breve ≥ 0.15 cap above.
- ‘ “ are mirrored dashes of ’ ” (a dash is point-symmetric, a 180° rotation would be identical to ’ ”); sheet-approved, so no rotated copy (skill item 24 applies to ball commas).
- Charset: basic set (Cyrillic, Latin, digits, punctuation of core_basic_n1: « » „ “ ” ‘ ’ … — – ‒ − · • © ₽ № @ # % * + = ° \ |, NBSP, U+2009, U+202F). [ ] < > _ ~ $ € § ‹ › are drawn in the generator but are not in the basic set.
- Lessons: (1) the host range of a slider comes from F.params[k] = [label, lo, hi, step], not from PARAMS; (2) holes by vector contour, not by raster (raster at 3 u invents 1-px holes); (3) fix geometry adaptively (S-aware dots/rings) before narrowing; (4) check parity through the same seed AND keep the net out of the parity run (defaults never trigger it); (5) homoglyph pairs must be one GL entry or homo fails.
