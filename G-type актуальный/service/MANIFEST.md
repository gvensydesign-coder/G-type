## Draw: tool «Ячейки» (cell grid; ui_draw_n7.js «Ячейки» block + core_draw_n7.js `DRC`; tests/e2e_cells.py, lane `e2e cells` in check.sh slow)
- Tool «Ячейки» (key `=` or `+`; key `7` goes to the glyph «7»; tools 1–6 keep digits): pencil/eraser on a grid of cells (3–24 columns × 3–24 rows, 0–4 rows below the baseline; cell = 700/rows, so the grid maps onto cap height 700 and the metric lines stay valid). Brush 1–7 cells (square footprint); drag fills every cell on the path (Bresenham between pointer samples, no gaps).
- Data: a glyph holds 1–8 cell layers (`CL_MAX`); each layer = ordinary item `{k:'add',t:'cells',cs:<ink>,cl:{g:<settings>,c:[i,j,…],s:[i,j,…]}}`. `c` = main cells, `s` = sub-grid cells (half size), j counts up from the baseline (negative below). `cs` is regenerated from `cl` (cache: exact contours only after a gesture/settings change; during a drag a coarse raster preview, once per frame). Because it is a normal item, undo/redo, save (`drnEval`), font build, `GT_DRAW` persistence and old saves keep working; the select/transform tools skip cell layers; mirror flips the cell data.
- Settings `g` (`drcNorm`): shape A/B (circle, square, diamond, triangle, pentagon, hexagon, octagon) + «Переход» 0–100 % (polar-radius morph A→B), rotation 0–360°, cols, rows, desc, brush size, joint rounding 0–100 % (closing radius = rnd/100 · cell/2), sub-grid on/off with its own shape (or linked to the main one). `D.cs` = settings shown in the panel; link mode `D.link`: «Нет» (per glyph, the panel adopts the glyph's settings), «Сетки» (shape/size/sub-grid keys shared), «Все настройки» (also size, rounding). Shared changes recompute other glyphs lazily (one glyph per tick, `cellFlushAll()` before build/test/persist).
- Geometry (`drcInk`): cell polygons + straight bridges between side neighbours (bridge band = the shape's own extent perpendicular to the bridge, asymmetric for triangle/pentagon, NOT capped at one cell; with «Скругление стыков» 0 the band is capped to one cell so the shape texture stays visible; chosen because runs of hex/octagon/rotated squares then give straight edges, e2e_cells checks spread < 1.5 units) → one raster mask (`csgMask`) → closing by a distance transform (`drcEdt`, concave corners get a fillet, convex corners are untouched: a lone cell is the exact cell shape, a 1-cell stroke end is a semicircle, a block corner keeps radius = cell radius; e2e_cells asserts deviation < 1 unit from the analytic capsule/circle) → `csgTrace` + `csgFit` (the same tracer/curve fitter as `csgUnionRaster`); specks/gaps below 0.1 cell are dropped. Checked for all shapes × rotations: no self-intersections (`cxCross`), ≤ ~190 nodes for a 30-cell letter.
- Transition: on a visible settings change the old and new signed-distance fields are blended per frame (bilinear, canvas alpha image) and replaced by the exact contours at the end; re-targeting mid-way continues from what is on screen.
- Storage: `gtype-draw-n7` item key `l:{g,c,s}`, root key `cg:{s:settings,l:link,v:showGrid,m:mode}`; the grid key is saved as the previous grid (`cell` is derived from the tool/layer, not stored).
- Panel sync: `cellSet` re-renders the panel (unless a range inside it has focus, so a drag is not interrupted), so the chips/labels/status always match the glyph's effective settings. Status line: `N ячейка/ячейки/ячеек · 1 слой`, empty layer «Пока пусто: проведите по сетке».
- Shape icons (`CL_ICO`): 24-grid, circumradius ≈ 9–10, miter joins in `.dr-shp` so hexagon (pointy sides) and octagon (flat top, longer edges) stay distinguishable at 16–18 px.
- Segmented controls (`ui_motion.js` 6.4): when the buttons of a `.dr-seg/.seg/...` are re-rendered with innerHTML the detached `.mo-ind` indicator is re-attached (it was lost, leaving the active tab text white on a light chip: «Базовая кириллица» unreadable); the MutationObserver now also queues a segment whose buttons were replaced.
- Layers (m83): panel «Сетка ячеек» starts with the layers list (eye, name, cell count) + buttons add / duplicate / rename / up / down / delete (delete of a non-empty layer asks in-page: «Удалить «…»? Удалить / Отмена»; no confirm()), then the status line `N ячеек · K слоёв` (`plur`: 1 слой, 2–4 слоя, 5+ слоёв, 11–19 слоёв, 21 слой) and the hint «Скрытые слои не попадают в шрифт» (shown with 2+ layers). Name: double-click or pencil, inline `<input>`, Enter/blur commits, Esc cancels, empty = unchanged, ≤24 chars; unnamed (old data) = «Слой k». Everything the panel edits (shape A/B, Переход, Поворот, Столбцы, Строки, Нижние ряды, Скругление, Подсетка…) belongs to the ACTIVE layer (`it.cl.g`); the brush size is kept when the active layer changes. Drawing/erasing/«Очистить слой» touch only the active layer (clearing the only layer removes it; with several layers it stays empty; an emptied only-layer is dropped as before; drawing into a hidden layer unhides it in the same undo step).
- Ink: every layer is fused on its own (`cellRegen`, cache `it.cs/_p/_fld`, only the changed layer is recomputed; the morph animation `ANI` runs on the active layer); `drnEval` skips items with `cl.h`, so the glyph ink = union of the visible layers' contours + the glyph's other items. Hidden layers are not drawn on the canvas and are not in the saved glyph/font (toggling visibility on a saved glyph re-evaluates on the next commit/build; if nothing visible remains the glyph becomes unsaved). Only the active layer shows its grid outline. Glyph advance follows the active layer's columns/rows (as before: `cellSyncGp`).
- Links (Нет / Сетки / Все настройки) work by layer INDEX: `D.pl[k]` = project settings of layer k (persisted as `cg.pl`, `pl[0]` falls back to `cg.s`). A change on the active layer k updates `D.pl[k]` and, in linked modes, layer k of all other glyphs (lazily, one glyph per tick); on loading a glyph / undo / switching the link on, layers take `D.pl[k]` for the linked keys (glyphs with fewer layers are unaffected; a new layer starts as a copy of the active layer's settings and `pl[k]` follows it; reorder swaps `pl` entries so settings stay with the layer). «Нет»: layers stay independent, the panel adopts the active layer.
- Storage: item key `l:{g,c,s,n?,h?}`; old saves (one `l` without `n`/`h`, no `cg.pl`) load as one visible layer «Слой 1»; empty layers are persisted (`unpackItems` keeps items with `l` even without ink).
- Mirror: cell shape polygons are symmetric about the vertical axis, so a true geometric mirror is `rot → −rot` (horizontal) and `rot → 180°−rot` (vertical) for ANY shape (triangle/pentagon included); the same for `srot`; cells are mirrored in the grid. e2e `cells-mirror` checks the XOR of mirrored-old vs new ink (tri/pent/square × 0°/17° × both axes, ≤ 0.6 % of the ink samples). Because rotation is linked, a mirror in a linked project updates `pl` rot/srot like a settings change.
- Known gaps: a triangle/pentagon always points up before rotation; vertical mirror of cells flips about the rows-desc box centre (other shapes about cap height) when «Нижние ряды» > 0.

## Stage 5A (history persistence, compressed engines)
- **History persistence** (`ui_hist.js`; no change was needed in `ui_draw_n7.js`: `GT_DRAW.hist.ready/ser/apply/glyph` already carry everything). One timeline per font (`ed:<fontId>`) and one for the draw view (`dr`) now live across font switches and reloads. `activate` no longer resets: `recon()` compares the in-memory timeline with the font state (key-order tolerant, `eqc`) and moves the pointer to the equal entry, or appends one new entry when the state differs (project loaded / reset elsewhere). A timeline that is not in memory is created from the current state and `pull()`s the stored one asynchronously; the stored entries are put in front (its pointer is reconciled with the session's first state), so edits made before the read finished are kept. In memory the current font plus 2 others stay (`KEEP_MEM`); older ones are written and dropped (dropped ones come back through `pull`).
- **Store** (`stOpen/stGet/stPut/stDel`, never rejects, every access in try/catch): IndexedDB `gtype-hist-v1/h` first; if it cannot be opened, localStorage `gtype-hist-v1:<key>`; if neither works, memory only (no error, no toast). ## Stage 5B (one-click proof fixes, auto-spacing and auto-kerning for drawn fonts)
- **Proof fixes** (`ui_proof_fix.js`, before `ui_hist.js` in `assemble.py`; CSS «Stage 5B» after `.pa .chip` in `template.html`; `window.PFIX_API` for tests).
