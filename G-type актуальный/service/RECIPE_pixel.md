# Recipe: «Пиксель» (Pixel Grid) — cell-grid display font. core_pixel_p1.js = pix/{engine,glyphs1-5,render,alts,reg}.js (mk_pixel.sh), UI ui_pixel_p1.js
Idea: glyphs are bitmaps of exact grid cells re-rasterised from recipes per resolution (6..24 cells per cap height) and merged into clean unions; grotesk (NeueBit-like) + optional pixel serifs (Mondwest-like); italic = whole-row shear (row y shifts floor(y/st)).
1. Context (engine.js ctx): H=res, X=0.7H (5 for H<=6), D=0.27H; weight ladder pw 1..5 step .5 -> [stem sv, bar sh] = [1,1] [2,1] [2,2] [3,2] [3,3] [4,3] [4,4] [5,4] [5,5]; serif: sh*0.6, K.sf serif length (1/2/3 by H), K.sfh height.
2. Recipes (glyphs1-5): caps from rings (rounded by corner-inset table), bars, stems and diagonals. Lowercase Cyrillic = small-cap recipe at x-height via sub() (bar height capped at (h-2)/3 so counters survive). Twins (А a е о р с у х м/m …) share one recipe. Latin m = Cyrillic м (small-cap М: stems + V); the arched m is ss01 ('m.ss01').
3. Diagonals keep the stem weight: run = sv*sqrt(1+m^2) (PXE.dlw) for A V W X Y K M N Z v w x y; 4-connected by construction (P.ln / connect()).
4. Л/л: right stem + top bar + left leg that curves to the baseline (leg width = stem, own width sv+gap+sv+S). Й: breve = cup with 2-wide ends, height mh(+1 from res 12).
5. Weights (pxFam, reg.js): Light/Regular/Bold/Black pw = r<=9 [1,1.5,2,2]; 10 [1,1.5,2,2.5]; 11-15 [1.5,2,2.5,3]; 16-17 [1.5,2.5,3,3.5]; 18-19 [2,2.5,3.5,4]; 20+ [2,3,4,5], capped by the limit table; Bold >= 1.25x Regular wherever the table allows.
6. Limit table (pix/limits.json, built by gen_limits.js from topology = same ink parts/holes as the res12/pw1.5 reference, for glyphs, OT alternates, marks): max pw per res and serif; rmin = lowest res that passes (6). Every slider combination therefore keeps topology (stress.js pixel, 0 bad).
7. Serif pass (addSerifs): feet/flags at free stem ends; each group is dropped if it adds a hole or a part. Heavy-weight guards: HC set (3 ? & Æ Đ G …) caps bar height to (H-3)/4; slash overlays cross the counter corner to corner.
8. Grid shape (square/dot/rounded/diamond, gap %, row/column stagger) is applied at contour level (render.js) and never changes advances; kerning is measured on the solid grid (topoP) so gaps do not disturb spacing.
9. Brush/eraser: ui_pixel_p1.js, edits per resolution in S.edits[ch].px[res] {a:[],d:[]} applied on recipe cells before shear; kept when resolution changes.
Misread audit (r8, r12): З/3, О/0, I/l/1, Б/6, Ч/4/У, Л/7, м/т, п/л, ш/щ — checked with pix/pv.sh (cell preview) and qa_PX/audit8.png, audit12.png. Tools: pix/pv.sh text res pw serif out.png; pix/sheets.sh, sheets2.sh (key sheets in qa_PX).
Lessons: sub() must rebuild prims (closures hold the old K); never widen P.dg globally (chevrons/3/? lost counters); kern from the solid grid; heavy-weight failures are always counters of rare glyphs, fix per glyph, do not lower the limit.
10. Variable font (pix/vf.js, PXVF; `node vf.js pixel out`, export «Вариативный»): wght 300–900 (Light/Regular/Bold/Black = 300/400/700/900), regular + italic, other axes disabled (VFX_FONT_AXES.pixel). Static weights re-lay the cells, so the VF keeps ONE topology = the Regular cell map (pw of the Regular ladder step) and expresses weight as a rectilinear offset of its merged outline: vertex k is the same vertex in every master (point-compatible, core3v matcher bypassed for pixel, vfDefect off). dx/dy per face = (static sv/sh of the master − Regular)/2 (PXE.ctx via pxFam); Black +0.25 cell beyond Bold when the static ladder gives Bold == Black. x: left faces stay, right faces move 2dx; y: symmetric offset + piecewise remap pinning baseline/x-height/cap/descender. Static Bold/Black glyphs are wider (counters keep width): the missing width goes to the emptiest columns (integer cells), so 1-cell slits (ш щ м) stay open and advances match the family (~0.99). Per glyph/master the offset is scaled back (fx, fy) where a stroke/counter would close (clearance PXVF.EPS=0.34 cell; edges keep direction, no crossings except outer/outer overlaps = union under nonzero fill); locked pinches stay at Regular. Grid shape: square or rounded (pshape 2) kept; dot/diamond/gap/stagger are not exported. Checks: tests/pxvf_check.py (structure, gvar via instancer at 10 weights, per-glyph geometry, instances vs static family), tests/e2e_pxvf.py (export menu). Lessons: pxFam('@vf') must map to Regular (FAM_W has '@vf' appended -> index 4 -> default pw 1.5); face-based "grid-aligned" y growth (top fixed/bottom moves) locks 1-cell tips and rounded corners (50+ glyphs) - symmetric offset + remap does not; static XOR vs VF is 0.00 at Regular, 0.07-0.16 mean at other weights (different cell layout).
