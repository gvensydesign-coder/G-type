# Recipe: «Сцепка» (Stsepka Display, id stsepka, card «Сцепка 2026») — narrow rounded constructor display font with real ligatures. core_stsepka.js = stsepka/{engine,letters,glyphs,spacing,lig,api,tail}.js (mk_stsepka.sh); stress: stress_stsepka.js; e2e: tests/e2e_stsepka.py

Idea: every letter is a stack of SHARP rectangles/parallelograms; neighbours are joined into one sign by a shared stem, roof, shelf, nest or foot (constructor ligatures). Approved reference: Python design (lock_s1, v6, Й variant A), ported 1:1 to JS.
1. Pipeline (engine.js): sharp pieces (solid/hole) -> solids rastered at 2 px/u (pixel-centre even-odd), holes zeroed GLOBALLY from the union -> crack-following contour trace (ink on the left, right turn at saddles) -> closed Douglas-Peucker (2.2 px) -> snap to 0.5-u lattice -> ONE fillet radius: convex R = rnd·S, concave R/2, turns < 14 deg stay straight, tangent clamped to half the edge -> cubic Béziers (handle 4/3·tan(θ/4)·r, arcs > 90 deg split). Glyph entries use opt.fixed (no host optical spacing, no wdth scaling).
2. Params (tail.js): stem = S 112–164 (Насыщенность), wdth 85–125 (Ширина), xh 420–588 (Высота строчных, lcr = xh/700), zrnd 5–70 % (Скругление), zgap 14–60 (Зазор сцепки), zjump 0–150 % (Скачут строчные), zlig 0/1/2 (Сцепки: Обычные/Все/Выкл; chips, slider hidden). fmt() of the host panel rounds to 1 decimal, so rnd and jump are in percent. Everything else is null (hidden) and fixed in paramLimits; sb forced 0.
3. Spacing (spacing.js): white-area balance, sb = max(SMIN, A − 0.5·mean_band(min(depth, CAP))), kern = area(Н–Н) − area(pair), clearance floor CLR = g; all terms scale with g. Edge rows are measured the way the reference measures them: 0.5 px/u PIL raster (vertices truncated, 2x supersample, BILINEAR, >127), not exact edges. Exact edges moved kerning by ±1 u and the no-near-touch rule slipped (18 pairs under 0.8 g instead of 12; reference 5).
4. Kerning in the host: classKernTable wrapped, one class per char, vals = lazy Proxy over D.kern (ownKeys returns a fake key so the exporter sees a non-empty table, pairs empty). Matrix < 64 KB, live slider drag stays fast, user overrides (st.kc) still apply.
5. Ligatures: GSUB type 4 built in otFeaturesO1 wrapper: ss02 lookup (28 dense caps + 24 lowercase + МИН) then calt lookup (34 caps pairs: 18 Cyr + 16 Lat), ss01 «Без сцепок» (name ID 256, single subst letter -> letter.ss01) is first in the lookup list, ss02 name ID 257 (core3b). Glyph names AGL: uni041D_uni041D.liga, N_N.liga; ss01 clones carry kernAs (core15 puts them in the kerning classes of their base). A ligature that cannot be built at the current params is not written (otAltOk wrapper + buildTTF current-param hook).
6. Preview: samples draw from outlines, so ui_stsepka.js wraps layout/ttLayout: STS.apply replaces sequences by U+F8xx (OTU.ch) in the same order as HarfBuzz (ss02, then calt); mode from the style params.
7. Weights: Light 118 / Regular 138 / Bold 152 / Black 164 (scaled by stem/138, clamped 112–164), WSCALE.stsepka 0.869. Bold/Regular stem ratio is only 1.10 (ParaType wants 1.25): the S range stops at 164 where counters of Ш Щ Ж close (stress limit).
8. Italic = oblique shear 10 deg (default slant), no VF. Basic charset + NBSP/thin/NNBSP registered explicitly (applik-style fonts created before core_basic_n1 do not get them automatically).
9. Metadata: tags disp, narrow, exp, basic, cl; collections «Для логотипа» and «Для вывески и плаката» (6-font cap: applik left the sign band, it stays in kids and exp); META_FAM stsepka (rounded sans).
## Known properties
- О = 0 identical (as in the approved reference): the status plaque honestly says «Могут путаться: буква «О» и цифра «0»». Latin y and Cyrillic у are different recipes (homo.js skips that pair). «@» is a plain ring.
- Ligature glyphs are not kerned against neighbours (outline carries baked sidebearings).
