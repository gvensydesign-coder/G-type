# G-type

Студия восстановления параметрической шрифтовой платформы G-type.

Рабочий сервис — `public/g-type-v96.html`. Его собирает `python3 service/build.py` из исходников архива v94 (11 ноября 2026) в папке `service/`. Слой `service/delta/` поднимает эту сборку до упакованной v96. Патчи рейла, лаборатории и искажения вшиваются в конец страницы.

Актуальная сборка лежит в папке [«G-type актуальный»](https://github.com/gvensydesign-coder/G-type/tree/main/G-type%20%D0%B0%D0%BA%D1%82%D1%83%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9) репозитория [gvensydesign-coder/G-type](https://github.com/gvensydesign-coder/G-type). В корне того репозитория по-прежнему экспорт Claude от 13 ноября 2026. Полный архив `G-type_project_v94.zip` в ту выгрузку не входил; исходники сервиса из него теперь в `service/`. После каждого шага эта папка обновляется целиком.

Рядом с сервисом открываются:

- прототип «Свой шрифт 2.0» (11 ноября 2026, 22:26 МСК), утверждённый к входу в v94;
- демо «Искажение» (12 ноября 2026, 19:34 МСК) — отдельная страница-образец; в сервисе инструмент стоит в рейле редактора и пишется в скачиваемый файл;
- дизайн-система v40 (27 октября 2026) и слой `public/design-system/later.css`, которым превью догоняют живую страницу;
- навык дизайн-системы и навык анимации `ui-motion`;
- план в `docs/PLAN.md`.

## Запуск

```bash
python3 service/build.py
npm install
npm run dev
```

Сервер слушает порт 4177. `npm run assemble` повторяет сборку страницы.

## Навыки

- `.cursor/skills/g-type-design-system/SKILL.md` — цвет, форма, рейл, экраны, искажение и оси вариативного файла. Токены v40 в соседнем `tokens.json`. Более поздние решения в самом навыке и в `later.css` заменяют снимок.
- `.cursor/skills/ui-motion/SKILL.md` — длительности, кривые, пружины, демо-сцены и проверка движения. Этот навык заменяет короткий раздел «Движение» из README v40.

После каждого подхода обновляй навык, этот файл, `docs/PLAN.md` и `later.css`, если менялись цвет, рейл, экраны или состав скачиваемого файла. Затем выгружай дерево в папку «G-type актуальный».

## Чего нет

Эскизы, снимки проверок и книги из архива в репозиторий не копировались: для сборки сервиса они не нужны. Отдельных гарнитур «Кисть» и «Афиша» нет: «Кисть» — инструмент рисования, «Афиша» — пресет «Столба».
