## Изменения

1. CI собирает страницу из исходников, сравнивает два последовательных результата, сравнивает опубликованный HTML по распакованным блокам (разные версии zlib могут дать разные байты), запускает lint, production build, `test:v96 --strict` и `tests/audit`. Python-зависимости для проверки шрифтов закреплены версиями. Сборщик работает с `patch` и `git apply`, записывает HTML с LF на всех платформах. Контрольные SHA исходных блоков обновлены после изменений, проверка хэшей не отключена.
2. В предпросмотре экспорта Unicode-пробелы исключены из предупреждения о пустых знаках. Имена предпросмотра учитывают фактическое семейство, вес, стиль и суффикс вариативного архива. Тест сравнивает 72 пары «предпросмотр/скачивание» и четыре имени архивов.
3. Тепловая карта лучше замечает касания заглавных и даёт действие для исправляемой пары в Аппликации. Когда исправление кернинга достигает предела, интерфейс сообщает об этом и не меняет скрыто боковое поле глифа. Искажение показывает варианты, позволяет выбрать и применить вариант; чипы эффектов получили действие.
4. Сравнение не очищает выбранные черновики до готовности хранилища. Добавлен сценарий повторной загрузки с двумя черновиками.
5. Парсер SVG ограничивает глубину (128) и число узлов (50 000), возвращая понятный результат `complex` вместо переполнения стека.

Изменения не мигрируют пользовательские данные и не правят исходные контуры, метрики, Unicode-карты или OpenType-таблицы. Изменения алгоритма карты влияют на оценку и на явно вызванное исправление; экспорт с активным искажением меняется по выбору пользователя. Откат — возврат commit этого PR.

## Проверки

- Локальная среда: Node 24.22.1, Python 3.12.14, Microsoft Edge headless. Архив v94 и доступные файлы v96 сверены с blob SHA исходного commit. Недостающие `blank-partial.png` и `proto/iskazhenie.html` восстановлены из исходного commit по SHA; это не изменения PR.
- Сборка: две последовательные сборки после нормализации LF дали одинаковый SHA-256 `3776B7A334E7EE08822233411D4EF7E6F758E66D4F2F821B59F574DA6EECFE9C`. Исходный `layout.js` локально восстановлен побайтно из baseline (без завершающего LF; SHA `2ff69df1f60457cbf6ef46a82bd445aae68be5e2`), чтобы опубликованный HTML совпал со сборкой Linux. Итоговый blob SHA HTML `80a4690dc1cb1354b17b487f5a18cca0a845b1c3`.
- Новые проверки: `export-preview`, `export-filenames`, `safe-fix`, `svg-limits` и браузерный тест чипов и вариантов искажения прошли (7/7; SVG 3/3). Тепловая карта: 17/17.
- Полный `node tests/v96/run.mjs --strict`: **99 passed, 8 failed, 0 pending, 451 s**. Никакая ошибка не переведена в «успех».
