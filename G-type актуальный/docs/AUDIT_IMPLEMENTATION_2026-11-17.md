## Изменения

1. CI собирает страницу из исходников, сравнивает два последовательных результата, сравнивает опубликованный HTML по распакованным блокам (разные версии zlib могут дать разные байты), запускает lint, production build, `test:v96 --strict` и `tests/audit`. Python-зависимости для проверки шрифтов закреплены версиями. Сборщик работает с `patch` и `git apply`, записывает HTML с LF на всех платформах. Контрольные SHA исходных блоков обновлены после изменений, проверка хэшей не отключена.
2. В предпросмотре экспорта Unicode-пробелы исключены из предупреждения о пустых знаках. Имена предпросмотра учитывают фактическое семейство, вес, стиль и суффикс вариативного архива. Тест сравнивает 72 пары «предпросмотр/скачивание» и четыре имени архивов.
3. Тепловая карта лучше замечает касания заглавных и даёт действие для исправляемой пары в Аппликации. Когда исправление кернинга достигает предела, интерфейс сообщает об этом и не меняет скрыто боковое поле глифа. Искажение показывает варианты, позволяет выбрать и применить вариант; чипы эффектов получили действие.
4. Сравнение не очищает выбранные черновики до готовности хранилища. Добавлен сценарий повторной загрузки с двумя черновиками.
5. Парсер SVG ограничивает глубину (128) и число узлов (50 000), возвращая понятный результат `complex` вместо переполнения стека.
6. Для вложенного PostCSS в Next.js задан общий override на `8.5.33`, lockfile пересоздан. CI теперь останавливается при уязвимостях производственных зависимостей уровня moderate и выше.

Изменения не мигрируют пользовательские данные и не правят исходные контуры, метрики, Unicode-карты или OpenType-таблицы. Изменения алгоритма карты влияют на оценку и на явно вызванное исправление; экспорт с активным искажением меняется по выбору пользователя. Откат — возврат commit этого PR.

Локально `npm ci`, `npm run lint` и `npm run build` не запускались: доступ к npm из shell ограничен, в рабочей копии нет установленных зависимостей. В GitHub CI установка, сборка HTML, lint, production build и новые тесты прошли. На предыдущих прогонах lint выявил ошибки правил React Hooks для обычной функции типографики `useFont`, CommonJS `require`, имён анонимных компонентов и синтаксиса самостоятельного фрагмента `service/ryvok_body.js`. Последний собирается в обёртку и не запускается отдельно; он исключён только из самостоятельного lint. Для сервисных скриптов и тестов CommonJS узко отключены неприменимые правила; остальные правила и 3025 предупреждений сохраняются. Следующие шаги CI выполняются даже после ошибки lint, чтобы показать результаты production build и тестов. Подробный `npm audit --json` до исправления показал 16 затронутых узлов дерева зависимостей (6 moderate, 10 high); это число пакетов в графе, а не число независимых CVE. Старый вложенный PostCSS `8.4.31` в Next.js заменён на `8.5.33`. На [диагностическом прогоне](https://github.com/gvensydesign-coder/G-type/actions/runs/44169100647) `npm audit --omit=dev --json` вернул 0 уязвимых узлов. Полный аудит ещё показывает 14 затронутых узлов (5 moderate, 9 high), все в инструментах разработки, главным образом через `picomatch` и `minimatch`. Для [picomatch](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) исправленной версии пока нет; принудительное понижение `eslint-config-next`/Next.js не выполнялось из-за риска регрессий.
